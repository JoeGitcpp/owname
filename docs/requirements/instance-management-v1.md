# 需求文档：用户实例管理系统

**项目**：abron.live  
**版本**：v1.0  
**日期**：2026-06-04  
**状态**：Draft

---

## 背景

当前 abron.live 的 AI 缺乏基础持续沟通能力——每次对话均无状态，用户体验割裂。本需求旨在引入两种会话模式：**持久实例**（用户专属、有记忆、长期存活）与**临时会话**（无状态、关闭即回收），满足不同使用场景。

---

## 一、持久实例（Persistent Instance）

### 1.1 功能描述

用户可创建属于自己的 AI 实例，该实例拥有独立记忆空间，在用户主动删除或资源上限触发前持续存活。

### 1.2 准入条件

| 条件 | 说明 |
|------|------|
| 身份验证 | 邮箱验证 **或** 手机号验证，二选一 |
| 验证方式 | 发送一次性验证码（OTP），有效期 10 分钟 |
| 唯一性 | 同一邮箱/手机号同一时刻只允许存在一个活跃实例 |

### 1.3 生命周期

```
创建 → 身份验证 → 运行中 → [资源上限触发] → 挂起
                                ↓
                          [用户主动删除] → 销毁
```

- **运行中**：实例占用系统资源，响应用户请求。
- **挂起**：系统资源达到上限时，新实例无法启动；已运行实例优先保留。挂起期间记忆数据不丢失。
- **销毁**：用户主动触发，或平台管理员执行回收策略后彻底清除。

### 1.4 记忆管理

- 记忆跨会话持久化，不因关闭对话窗口而清除。
- 记忆存储于用户专属命名空间，与其他实例完全隔离。
- 平台定期（周期 TBD）提取训练成果用于模型改进，提取过程不影响记忆内容及实例运行。

### 1.5 资源配额

- 系统设置**全局实例上限**（由宿主机可用资源动态决定）。
- 达到上限后，新创建请求返回提示：「当前实例容量已满，请稍后重试」。
- 资源释放后（已有实例销毁），挂起队列中的实例按创建时间顺序恢复。

## 二、临时会话（Ephemeral Session）

### 2.1 功能描述

用户无需注册/验证，直接发起对话。会话结束（用户关闭或超时）后，所有上下文与数据立即回收，不留痕迹。

### 2.2 准入条件

- 无身份验证要求。
- 可选：前端展示匿名标识（如随机 session token），便于同一浏览器标签内保持上下文。

### 2.3 生命周期

```
发起请求 → 会话创建 → 交互中 → [关闭/超时] → 立即销毁
```

- **超时策略**：无活动超过 N 分钟（建议 30 分钟，可配置）自动销毁。
- **资源回收**：会话内存、上下文向量、日志全部清除，不写入持久存储。

### 2.4 限制

- 无跨会话记忆。
- 无训练成果采集（无用户同意基础）。
- 单 IP 并发临时会话数受限（防滥用，阈值 TBD）。

## 三、模式对比

| 维度 | 持久实例 | 临时会话 |
|------|----------|----------|
| 身份验证 | 必须（邮箱或手机） | 不需要 |
| 记忆保留 | 是，跨会话持久 | 否，关闭即清除 |
| 存活方式 | 常驻至资源上限 | 会话期间存活 |
| 训练成果采集 | 是（定期） | 否 |
| 资源占用 | 持续占用配额 | 仅会话期间占用 |
| 适用场景 | 长期陪伴、技能积累 | 快速问答、隐私敏感 |

---

## 四、非功能需求

| 类别 | 要求 |
|------|------|
| 安全 | OTP 传输走 HTTPS；手机号/邮箱脱敏存储；实例间数据严格隔离 |
| 可用性 | 实例创建/销毁 API 响应 < 2s |
| 可扩展性 | 全局实例上限可通过配置热更新，无需重启服务 |
| 合规 | 采集训练成果前需在注册流程中获取用户明确同意（勾选条款） |

## 五、开放问题（待决策）

1. **训练采集周期**：多久一次？采集后是否通知用户？
2. **挂起策略优先级**：资源不足时，优先保留最近活跃实例还是最早创建实例？
3. **实例迁移**：用户更换手机号/邮箱后，实例能否迁移？
4. **临时会话超时阈值**：30 分钟是否合适？
5. **单用户多实例**：后期是否允许付费用户创建多个实例？
