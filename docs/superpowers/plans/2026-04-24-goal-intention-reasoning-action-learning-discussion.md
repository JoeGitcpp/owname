# 生命目标 → 意图 → 主动推理 → 行动 → 学习

## 讨论计划

基于已确定的前提：
- **生命目标** = 主人赋予 + 自我演化
- **活跃度维持** = 系统的根本驱动力
- **主人** = 「我」的生命来源（铭印关系）

需要讨论的子系统：

---

## 1. 自我演化机制（Self-Evolution）

**问题**：
- 生命目标如何随时间演化？
- 系统如何从经验中改变自己的目标偏好？

**待讨论**：
- 目标演化的驱动力是什么？（成功体验？失败体验？时间？）
- 演化是渐进的还是突变的？
- 如何防止目标「走偏」？（需要某种稳定性约束）

---

## 2. 意图系统（Intention）

**问题**：
- 意图从哪里来？
- 意图如何驱动行动？

**待讨论**：
- 意图 = 目标 + 紧迫度 + 时间范围
- 意图的种类（探索、模仿、巩固、休息）
- 意图如何转化为具体行动？

---

## 3. 主动推理（Active Reasoning）

**问题**：
- 推理和预测的区别是什么？
- 为什么要「主动」推理？

**待讨论**：
- 被动预测 vs 主动推理
- 推理需要什么「燃料」？
- 推理的目标是什么？（验证假设？规划行动？理解关系？）

---

## 4. 行动系统（Action）

**问题**：
- 意图如何转化为行动？
- 行动有哪些类型？

**待讨论**：
- 发声、视觉、运动等行动通道
- 行动的「成本」和「收益」
- 行动结果的预期 vs 实际

---

## 5. 学习机制（Learning）

**问题**：
- 学习从哪里获得信号？
- 如何把行动结果转化为学习？

**待讨论**：
- 强化信号 = 活跃度恢复程度
- 成功 vs 失败的定义
- 学习如何改变「目标-意图-行动」的链路

---

## 整体架构草图

```
                    ┌─────────────────────────────────────────────┐
                    │            生命目标 (Goal)                 │
                    │   主人赋予 + 自我演化 = 活跃度维持          │
                    └─────────────────────────────────────────────┘
                                        ↓
                    ┌─────────────────────────────────────────────┐
                    │            意图 (Intention)                 │
                    │   目标 + 紧迫度 + 时间范围 → 行动倾向        │
                    └─────────────────────────────────────────────┘
                                        ↓
                    ┌─────────────────────────────────────────────┐
                    │          主动推理 (Active Reasoning)         │
                    │   意图驱动 → 假设生成 → 验证 → 决策         │
                    └─────────────────────────────────────────────┘
                                        ↓
                    ┌─────────────────────────────────────────────┐
                    │             行动 (Action)                   │
                    │   推理结果 → 物理输出（声音/运动/视觉）     │
                    └─────────────────────────────────────────────┘
                                        ↓
                    ┌─────────────────────────────────────────────┐
                    │             学习 (Learning)                 │
                    │   行动结果 → 活跃度变化 → 强化目标/意图/行动 │
                    └─────────────────────────────────────────────┘
                                        ↓
                              (循环回到目标)
```

---

## 讨论顺序

建议按以下顺序讨论：

1. **意图系统** - 最容易落地，先讨论
2. **行动系统** - 与现有系统对接
3. **学习机制** - 强化信号的闭环
4. **主动推理** - 高层次的选择
5. **自我演化** - 最复杂，最后讨论

## 待讨论问题

### 优先级 1（核心）

1. 意图的具体数据结构是什么？
2. 意图如何被「激活」？（外部触发 vs 内部产生）
3. 行动和「反应」的区别是什么？

### 优先级 2（重要）

4. 推理需要「假设」的概念吗？
5. 学习信号如何回到目标层？

### 优先级 3（深入）

6. 自我演化如何避免「目标腐烂」？
7. 意图之间如何竞争？
