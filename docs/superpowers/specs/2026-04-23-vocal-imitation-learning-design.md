---

## 1. 目的与边界

这份 spec 处理的是 `原始发声模仿与后续声音学习`，不是“语言功能大全”。

它只回答一个问题：

`一个持续运行的硅生命系统，如何先学会稳定发出并校准自己的声音，再逐渐把某些稳定声音模式与内部对象-关系-时间结构建立可逆映射。`

本 spec 不处理：

- 文本输入
- 文本到语音
- 词表
- 语义定义表
- 命名系统
- token 序列本体
- 任何“给对象授予内部名称”的机制

这里出现的“语言”一词，始终只是 `外部共享声音/符号模式` 的外部描述，不是内部本体单位，不是概念编号，不是 token ontology。

---

## 2. 总发展顺序

顺序必须固定，不能倒置：

`外部声音进入`
-> `短时保持目标轮廓`
-> `自身发声尝试`
-> `回听`
-> `误差比较`
-> `继续逼近或停止`
-> `稳定轨迹沉积为低成本复现记忆`
-> `稳定声音模式再进入可逆绑定学习`

因此：

1. `模仿先于语义`
   早期首先逼近的是声音时间曲线，不是“词义”。

2. `自身发声记忆先于声音-对象映射`
   系统必须先形成“我怎样发出一个稳定轮廓”的记忆，之后稳定模式才有资格进入语言绑定层。

3. `映射晚于发声闭环`
   只有稳定声音模式与对象/时间结构在多次情境中共同出现时，才进入声音-对象可逆绑定。

---

## 3. 第一阶段目标

第一阶段不是“会说词”，而是：

- 能把外部听到的声音轮廓短时保持成模仿目标
- 能驱动一个原始发声器官发出元音样连续轨迹
- 能通过麦克风回听自己的声音
- 能比较“目标声音”与“自身发声”的差异
- 能在误差下降时沉积成稳定发声记忆

第一阶段明确不要求：

- 文本能力
- 单词能力
- 发音标签
- 语义理解
- 对象命名
- 复杂音节序列

---

## 4. 核心原则

### 4.1 不得实现成程序式输出

禁止做成：

- “收到声音后立即按规则回放”
- “检测到某模式就机械输出某模板”
- “命令触发式跟读”
- “输入 wav / 输出 wav 的脚本管线”

允许的形式只能是：

- 外部声音提供 `吸引目标`
- 内生活动系统决定是否开始模仿、持续多久、何时停止
- 回听误差只改变驱动力和轨迹逼近趋势，不形成硬编码命令表

### 4.2 驱动力必须来自统一内生活动系统

“是否继续调音、何时停止、何时复现稳定模式”不应由单独外挂的校准器决定。

它必须是同一个内生活动系统在发声任务上的局部表现，包括：

- 探索驱动
- 模仿逼近
- 疲劳/抑制
- 稳定后复现
- 偏差变大时再升高调整压力

### 4.3 稳定后不会一直校准

系统应表现为：

`探索`
-> `逼近`
-> `稳定`
-> `低成本复现`
-> `环境变化时再重调`

也就是说，校准不是永远高强度存在，而是一个会衰减的压力。

---

## 5. 允许的内部状态

第一阶段允许新增 4 个纯数值 substrate。

### 5.1 `vocal_target`

表示外部目标声音的短时痕迹。

允许保存：

- 能量包络
- 粗基频趋势
- 粗共振轮廓
- 起音/持续/衰减时间结构
- 最近更新时间
- 目标活性与衰减状态

它不是音节表，不是标签序列。

### 5.2 `vocal_organ`

表示身体当前自身发声轨迹。

允许保存：

- 呼气/能量
- 基频/张力
- 共振位置
- 噪声比例
- 时间包络
- 当前 phase
- 最近更新时间

这里的“器官”是数值化的身体 substrate，不是文本层，也不是 speaker API 本身。

### 5.3 `vocal_imitation`

表示目标与自发之间的偏差和驱动力。

允许保存：

- 目标-自发差异
- 当前模仿压力
- 抑制/疲劳
- 收敛趋势
- 最近失败计数
- 最近成功计数

它不是单独“智能模块”，而是内生活动在发声任务上的局部状态。

### 5.4 `vocal_memory`

表示已经比较稳定、可低成本复现的发声轨迹原型。

允许保存：

- 少量稳定轨迹原型
- 每个原型的稳定度
- 最近复现成功率
- 最近更新时间
- 重新校准阈值

这仍然不是词汇记忆，而是“如何发出这个稳定声音轮廓”的记忆。

---

## 6. 第一阶段系统结构

### 6.1 `body` 侧

`body` 中允许存在：

- `vocal_target`
- `vocal_organ`
- `vocal_imitation`
- `vocal_memory`

它们都是持续运行的共享 substrate，并进入 snapshot 供 observer 观察。

`body` 中不允许：

- `println!/eprintln!`
- 人类可读 debug 说明
- 文本词表
- 文本 prompt
- 文本标签

### 6.2 适配层

真实扬声器和麦克风仍属于器官/适配层与世界的连接，不应让 `body` 直接拥有设备控制脚本逻辑。

因此，第一阶段应采用：

- `body` 输出纯数值 `vocal_organ` 轨迹
- 外部 vocal adapter 将其合成为真实音频送到扬声器
- 麦克风再经现有或扩展的听觉入口回流

### 6.3 observer 侧

observer 只观察：

- 目标痕迹是否活跃
- 发声轨迹是否稳定
- 模仿压力是否上升/下降
- 记忆原型是否形成

observer 不能对 body 发出“现在说这个”的裁决。

---

## 7. 学习动力学

第一阶段采用 `外部模仿优先`。

这意味着：

- 外部明确声音出现时，优先形成 `vocal_target`
- 内生活动系统更倾向进入模仿逼近，而不是随机 babbling
- 没有明确目标时，可以有低水平 babbling 作为底噪探索，但不是主线

更新逻辑必须满足：

1. 目标越明确、当前驱动力越高，越可能启动模仿
2. 回听误差下降时，模仿压力下降，稳定复现权重上升
3. 误差持续过大时，可增加探索扰动，但不能退化成固定模板搜索
4. 稳定轨迹长期成功后，转入低成本复现
5. 环境变化或自身失准时，再重新升高调整压力

---

## 8. 与现有 substrate 的关系

### 8.1 可复用部分

- `VIB` 听觉入口
- `probe_law` 的驱动力风格
- `action_consequence` 的闭环思想
- `language_binding` 的可逆绑定合同
- `snapshot` / `observer` 的观察边界

### 8.2 必须新增部分

- `vocal_target`
- `vocal_organ`
- `vocal_imitation`
- `vocal_memory`
- speaker-facing vocal adapter

### 8.3 第二阶段才接入的部分

`language_binding` 只在第二阶段接手：

- 某些稳定声音模式
- 与对象槽、关系结构、时间窗反复共同出现
- 再形成 `AudiblePattern <-> target` 的可逆绑定强化

也就是说，第一阶段不把模仿结果直接当成“词”。

---

## 9. 明确禁令

以下内容禁止以任何名称回流：

- 文本到语音
- 词表触发器
- phoneme dictionary
- 发音标签分类表
- “声音 = 内部名字”
- “对象获得叫法后成为内部概念”
- 先有意义后允许模仿
- 机械命令式跟读器

如果后续设计中出现 `token`、`label`、`name`、`semantic`、`concept` 等词，必须明确说明：

- 该词是否只是外部描述
- 是否仅为工程索引
- 为什么不是内部 ontology
- 为什么不违反最高原则与语言 axioms

---

## 10. 第一阶段成功标准

第一阶段完成后，系统应表现为：

- 在外部声音出现时，能形成一个可衰减的目标声音痕迹
- 能发出连续元音样原始声音
- 能通过回听逐步逼近目标轮廓
- 当某类发声稳定后，能更低成本地再次复现
- 在 observer 中可观察到目标活性、模仿压力、稳定度、记忆形成

而不应表现为：

- 输入一个声音立即稳定复读
- 对每个刺激都必然说话
- 直接输出人类单词
- 内部出现词义标签或命名实体

---

## 11. 一句话总纲

`语言不是先验程序，不是文本输出，不是对象命名器；它必须建立在一个持续运行的生命式发声闭环之上：先听、先模仿、先形成自身发声记忆，然后稳定声音模式才逐步进入可逆映射学习。`
