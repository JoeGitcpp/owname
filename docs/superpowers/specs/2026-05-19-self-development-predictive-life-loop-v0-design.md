# Self-Development Predictive Life Loop v0 Design

> **Status:** FROZEN CANDIDATE
> **Implementation status (2026-05-19):** v0 body-side
> `SelfDevelopmentState`, probe damping, body runtime order, snapshot v47,
> report mode, and TDD guards are implemented on
> `codex/self-development-predictive-life-loop-v0`.
> **Purpose:** correct the live-nursery direction by making body-side
> prediction improvement, stable recurrence sedimentation, and repetition
> suppression the first growth loop. External curricula and reports remain
> observers; they do not define life.

## Direction Correction

The current live nursery and product-baseline work proves that external
courses and observer reports can see activity. That is not enough. A body that
only passes external curriculum gates can still become a write/return machine
that repeats without improving prediction.

This design moves the first growth criterion back into the body:

```text
continuous ingress
-> local prediction gap
-> pressure and focus
-> active probe or quiet wait
-> return / non-return
-> prediction improvement or unresolved residue
-> sedimentation or suppression
```

The external description "knows the first long-present person" must be treated
only as an observer phrase. Internally it means:

- stable repeated PHOT/VIB/relation curves;
- reduced prediction gap after recurrence;
- bounded reentry when the curve disappears and returns;
- lower exploratory pressure around stable recurrence;
- no fixed person, face, identity, owner, or personality ontology.

## Boundary Notes For High-Risk Terms

`identity`, `owner`, and `personality` appear here only as forbidden internal
ontology examples. The body must not store or infer those units. The legal
replacement is numeric recurrence and prediction-change state. Any observer may
describe a stable recurrence as "familiar" or "recognition-like", but the body
only stores bounded scalar curves and timestamps.

`semantic`, `concept`, `token`, `label`, `name`, `word`, and `text
understanding` are not part of this design. If future teaching uses external
speech or visible marks, those enter through VIB/PHOT curves and existing
binding events, not through discrete word or concept IDs.

## Body-Side Substrate

Add one numeric substrate: `SelfDevelopmentState`.

It is not a controller, teacher, personality, child model, reward model, or
curriculum runner. It reads existing substrate signals and writes only bounded
numeric/time fields:

- `prediction_gap`: current maximum unresolved prediction pressure.
- `prediction_improvement`: positive change when current gap drops below the
  previous gap.
- `stable_recurrence`: repeated stable routing and pattern recurrence.
- `familiarity_pressure`: observer-visible sediment of stable recurrence plus
  prediction improvement.
- `repetition_pressure`: high write/return activity without useful closure or
  prediction improvement.
- `exploratory_pressure`: remaining pressure that should be allowed to probe.
- `output_suppression`: bounded inhibition applied to active probe output when
  repetition dominates.
- counters and timestamps for observer evidence.

The substrate reads:

- global reasoning surprise and routing memory;
- relation predictor surprise/confidence;
- active reasoning gap closure/reentry;
- evidence tension;
- action-output epoch count;
- action-consequence window/pair counts and pair curve similarity;
- prediction pressure field.

It does not read the observer, curriculum reports, teacher phase names, or
human-readable text.

## Runtime Order

The body refresh order becomes:

```text
attention
-> relations
-> relation predictor
-> reasoning
-> reasoning history
-> evidence tension
-> active gap
-> prediction pressure field
-> active surface
-> auditory/visual expression
-> self-development loop
-> probe law
-> probe output
-> snapshot
```

This lets active probe output be shaped by recent growth evidence instead of
raw pressure alone.

## Healthy Direction

A healthy early loop should show:

- prediction gap can rise from new events;
- stable recurrence can accumulate during repeated stable input;
- prediction improvement can appear when recurrence reduces gap;
- exploratory pressure remains available for unresolved events;
- repetitive write/return saturation raises suppression;
- suppression reduces output intensity without mutating sensory truth;
- observer evidence can see the loop without feeding it.

## Stop Conditions

Stop or gate live nursery sessions if:

- write epochs and return windows repeatedly saturate while prediction
  improvement stays near zero;
- output suppression remains high while no stable recurrence accumulates;
- snapshot evidence cannot distinguish useful recurrence from mechanical
  repetition;
- a proposed implementation adds fixed person, identity, owner, personality,
  word, concept, or semantic units to the body.

## v0 Acceptance

TDD acceptance must prove:

1. stable repeated low-gap recurrence raises `familiarity_pressure` without
   requiring a curriculum or teacher phase;
2. high repeated write/return activity with weak pair similarity raises
   `repetition_pressure` and `output_suppression`;
3. probe-law output is damped by `output_suppression` but remains possible
   when unresolved exploratory pressure dominates;
4. snapshot v47 serializes and reads `SelfDevelopmentState`;
5. a report mode can read live runtime evidence without using deterministic
   curriculum gates;
6. source guards reject fixed ontology and body-side human-readable output.
