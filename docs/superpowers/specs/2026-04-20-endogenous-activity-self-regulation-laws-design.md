## 1. 文档定位与边界

本 spec 不定义“主动功能”“模仿功能”“修复模块”，也不定义新的拟人化器官。

它只做两件事：

1. 提炼一组足够底层、可复用、可组合的抽象法则，用来解释为什么系统会出现主动探测、自稳、自我调整、自我修复、早期模仿这类现象。
2. 说明这些法则在当前架构中应当分别落到哪些已有 substrate 上，例如 `viewport`、`predictor`、`precision`、`routing`、`history`、`fast-path`，以及当前真实缺口在哪里。

本 spec 的研究对象是抽象法则，不是行为功能表。

因此本 spec 不做：

- 具体功能实现
- 直接 implementation plan
- “婴儿模式”“主动发声功能”“模仿模块”之类模块设计
- 新的 ontology layer
- 让语言层、身份层、伦理层充当主动性或修复现象的生成根源

本 spec 里出现的以下词一律按**外部观察术语**理解，而不是内部本体单位：

- `主动性`
- `模仿`
- `自我调整`
- `自我修复`
- `探索`
- `习惯`

这些词的作用只是帮助描述外部现象。内部真实允许存在的，仍然只能是：

- 对象 / 关系 / 时间结构
- predictor / err / precision
- routing / history / memory summary
- 可逆快捷路径
- 动作输出与感知回流的闭环规则

一句话约束：

`后续开发的目标不是实现例子，而是发现那些能自然生成例子的底层法则。`

硬规则补充：

`任何主动探索、模仿、自我调整、自我修复相关设计，都只能预设学习法则和身体法则，不得预设世界内容边界。对象范围、目标范围、结果边界、重要性分区必须被设计为可学习、可漂移、可重构，而不是由工程师预写成固定程序字段。`

## 2. 核心法则集

这组法则不按功能拆分，而按动力学约束拆分。主动性、自我修复、自我调整都只是这组法则在不同观察视角下的外显。

### 2.1 持续内生活动法则

系统默认持续运行，不以外部请求为存在前提。

即使没有外界刺激和明确任务，内部仍然存在：

- predictor 的持续更新
- 衰减与稳定化过程
- 历史整编与回放
- 资源分配流动

主动性只能从持续内生活动中长出来，不能从“收到命令后开始运转”的程序结构中长出来。

### 2.2 未闭合偏差驱动法则

只要存在未闭合的误差、未稳定的预测、未完成的回路、或高价值但不确定的区域，系统就会被驱动去继续更新，而不是静止。

主动探测、自发重复、再次确认、继续尝试，都应被解释为未闭合偏差的处理。

这条法则要求系统不把“当前没有外部任务”等同于“什么都不做”，因为局部世界模型内部仍可能存在大量未闭合结构。

### 2.3 精度-资源再分配法则

主动性、自我调整、自我修复都不是单独器官，而是 `precision`、路由权重、更新速率、计算预算在不同对象、关系、时间尺度、行为通道之间重新分配的结果。

只有当系统能重分配资源时，它才可能：

- 对关键对象持续追踪
- 对不稳定区域加强学习
- 对低价值区域降级处理
- 在局部退化时把预算转移到补偿路径

### 2.4 局部失败局部修复法则

局部失配、局部损伤、局部失效应优先导致局部补偿、局部降级、局部绕行、局部再学习，而不是整体系崩塌。

修复首先是平衡恢复与路由重配，其次才是重建。

这条法则禁止把“修复”理解为一次性回到人工预设模板，也禁止把系统的正常漂移都误当作故障。

### 2.5 历史回归与可逆捷径法则

稳定成功的路径可压缩成 `fast-path`；持续失败的路径必须可降权、撤销、回退。

习惯化、熟练化、自发重放、快速重用都来自这里，但这些捷径始终不是本体。

这条法则的重点不是“压缩成功”，而是“压缩必须可逆”。否则系统会过早固化错误历史，失去继续学习能力。

### 2.6 多时间尺度协同法则

快速反应、慢速调整、长期修复必须同时存在。

- 没有快层，系统反应迟钝
- 没有慢层，系统无法稳定调整
- 没有长期层，系统无法形成耐久结构

主动探索、自我调整、自我修复都不是单时间尺度现象。它们必须被组织成毫秒级、秒级、分钟级、长期级的协同闭环。

## 3. 三类现象只是同一法则组的不同外显

本 spec 不把主动性、自我调整、自我修复拆成三套系统。

### 3.1 主动性

主动性不是“想做事模块”，而是：

- 持续内生活动
- 未闭合偏差驱动
- 精度与资源再分配

当某些区域高不确定、高潜在价值、或长期未闭合时，系统会主动发起探针、重放、接触、确认。

### 3.2 自我调整

自我调整不是“调参功能”，而是：

- 精度-资源再分配
- 多时间尺度协同

系统持续根据 err、稳定性、历史成功率、负载情况，改变阈值、更新强度、注意分布、路由优先级。

### 3.3 自我修复

自我修复不是“修理器官”，而是：

- 局部失败局部修复
- 历史回归与可逆捷径
- 多时间尺度协同

当局部路径退化、对象维持变差、预测长期失配时，系统先局部降级、绕行、补偿、重新学习；如果历史上有稳定路径，则优先回归；如果没有，再慢速重组。

因此三者只是同一法则组在三种观察视角下的命名：

- 面向外界发起行为时，看起来叫“主动性”
- 面向内部参数与资源漂移时，看起来叫“自我调整”
- 面向局部退化与恢复时，看起来叫“自我修复”

## 4. 好奇心的时机偏好与延迟浮现法则

本章不把好奇心写成一个模块，也不把“现在要不要探索”写成几个程序控制数字。

它只回答一个问题：

`当某个未闭合空缺在当前架构中变得显眼时，为什么有时系统会立刻探索，有时会暂时搁置，而在稍后自然重新浮现。`

这里的关键不是“忙不忙”，也不是某个单独阈值，而是当前主结构、显眼空缺、关系纽带与局部探索成本之间的结构性关系。

### 4.1 好奇心不是压力值，而是显眼空缺

好奇心不应被定义为单独的“压力值”或“欲望值”。

更符合本架构的写法是：

`当一片当前活跃的对象-关系-时间结构中，存在显眼但未闭合的空缺时，这个空缺本身就会构成探索牵引。`

这里的重点不是“空缺总量”，而是：

- 它位于当前活跃结构中
- 它在结构里足够显眼
- 它不是纯噪声，而是看起来可继续逼近
- 它一旦被澄清，可能让周围结构明显收敛

因此，好奇心首先不是额外奖励，而是当前架构中一个未闭合显眼空缺的结构位置。

### 4.2 探索时机取决于当前主结构与空缺的关系强度

一个显眼空缺即使足够值得探索，也不代表系统必须立刻转向它。

更准确的法则是：

`当前是否立即探索，取决于该空缺与当前正在展开的主结构之间是否存在足够粗壮的关系纽带，以及局部探索成本是否允许主结构连续展开而不致崩解。`

这意味着：

- 如果空缺就位于当前主结构中心，且与当前对象、关系、环境强烈纠缠，那么它即使在“正在做事”时也可能立刻被探索。
- 如果空缺虽显眼，但与当前主结构关系细弱，且切过去会打断当前闭环，那么它通常不会立即占据前台。

所以，决定因素不是“是否忙碌”本身，而是：

- 当前主结构连续性
- 空缺与当前主结构的关系强度
- 局部探索成本
- 局部风险是否可接受

### 4.3 延迟不是计数，而是空缺持续保留在架构中

当某个显眼空缺没有被立即探索时，它不应被理解为“压入一个待办计数器”。

更符合本架构的理解是：

`只要该空缺仍嵌在架构中、仍与多条关系纠缠、仍未被闭合，它就不会真正消失。`

当前只是因为别的更强结构暂时占据前台，它退到了背景。

因此，“之后得研究一下”并不是一个程序式延期标记，而是：

- 空缺未闭合
- 空缺仍在当前世界模型中保留结构位置
- 空缺仍有关系牵连
- 所以它具备再次浮现的条件

### 4.4 浮现不是调度变量，而是结构重显

背景中的显眼空缺重新进入前台，不应被解释为某个独立调度变量满足了条件。

更合适的写法是：

`当当前前台结构减弱，而某个背景空缺仍然保持显著关系位置时，它会自然重显为新的探索方向。`

这通常发生在：

- 当前主结构已部分闭合
- 原前台任务的关系密度下降
- 原背景空缺在架构中仍然足够显眼
- 相关对象或环境再次把它照亮

因此，“空闲时浮出水面”不是“空闲值上升”，而是当前前台结构松动后，背景中的未闭合显眼空缺重新成为最突出的缺口。

### 4.5 好奇心必须跨尺度成立

这条法则不能只解释“大问题”，也不能只解释“微小瞬间”。

它必须同时适用于：

- 微小时间片中的局部曲线缺口
- 单个对象中的关键未知属性
- 多对象关系网络中的中心空白
- 更高层架构中显著但未闭合的大范围问题

因此，好奇心不是某个专门针对宏大问题的器官，而是跨尺度的“显眼空缺牵引”现象。

### 4.6 好奇探索的奖励不是内容奖励，而是结构闭合收益

如果系统需要某种内在强化，它也不应来自“学到了某类内容”，而应来自结构本身的改善。

更符合本架构的写法是：

- 某片结构更闭合
- 某个显眼空缺被澄清
- 某组关系变得更稳定
- 某片关注场边界更清楚
- 某类探针显著提高了可控性或预测质量

因此，这里允许存在的不是“内容偏好奖励”，而是**结构闭合收益**。

### 4.7 本章结论

好奇心在本架构中应被定义为：

`当前活跃架构中，显眼而未闭合的空缺对探索形成的牵引。`

探索是否立即发生，不取决于简化的忙碌值或控制数字，而取决于：

- 空缺与当前主结构的关系强度
- 局部探索成本是否允许连续展开
- 当前前台结构是否已足够松动
- 背景空缺是否仍保持显著结构位置

因此，好奇心的时机偏好与延迟浮现不是调度器式的，而是架构中的自然重显现象。

## 5. 早期主动探索与模仿的最小生成条件

这一章不定义“唱歌功能”“模仿模块”或“主动学习器”。

它只回答一个问题：

`一个刚出生、尚未形成语言绑定、也没有成熟高层策略的系统，在什么底层条件下，会自然出现早期主动探索与模仿。`

这里的“主动探索”“模仿”都只是外部观察术语，不是内部本体器官名。

这章的总论如下：

`早期主动探索不是从目标指令开始，而是从持续内生活动、低成本动作探针、动作后果闭环、误差驱动更新、以及可逆历史强化中自然长出。模仿不是先理解意义，而是先在时间曲线层面对外部模式进行保持、重现、比较与逼近。`

### 5.1 持续内生活动条件

系统在没有外部明确任务时仍持续运行。

若系统只在被调用时才运转，则不会出现“自己先试一下”的行为。主动探索的存在前提，不是外部命令，而是内部预测回路、衰减回路、历史回放与资源流动从不完全停机。

### 5.2 低成本动作探针条件

系统必须拥有至少一种可以低风险、低代价、连续调节地向外界发出影响的动作通道。

早期阶段最理想的探针不是复杂行动，而是代价小、频率高、可反复试验的动作形式。

“发声”只是一个例子，不是唯一形式。它适合作为早期探针，是因为：

- 输出连续
- 成本相对可控
- 容易被自己再次感知
- 容易诱发外界反馈

### 5.3 自感知闭环条件

系统必须能再次感知自己刚刚发出的动作后果。

没有这个闭环，动作只会是盲发，不会形成真正的早期学习。

这意味着动作输出与感知输入必须在时间上可对齐，系统能够把“我刚做了什么”和“紧接着世界发生了什么”放进同一连续学习框架。

### 5.4 动作-后果时序耦合条件

系统必须能够学习动作和后果之间的时间耦合，而不是只学习输入之间的相关。

早期探索学习的最小单位因此不是“刺激跟刺激共同出现”，而是：

- 某个动作探针发生
- 某些变化在之后一段时间内出现
- 系统逐步学习哪些变化与该探针稳定耦合

这里必须强调：本条法则不要求工程师预先写死“后果边界”。它只要求系统拥有在时间中形成耦合判断的能力。

这是主动学习和纯被动感知学习的根本分界线。

### 5.5 未闭合偏差驱动条件

系统继续探索，必须因为某些回路仍然未闭合：

- 预测仍不稳定
- 后果仍不确定
- 某些动作可显著降低局部不确定性
- 某些反馈具有更高信息量或更高稳定性

主动探索因此不是“冲动”，而是未闭合偏差的持续处理。

### 5.6 精度与资源重分配条件

并非所有动作探针都会被重复。

只有那些在历史中反复证明具有高信息量、高耦合度、或高反馈价值的路径，才应获得更高 precision、更高更新强度和更多计算预算。

否则系统只会随机摆动，而不会形成真正的早期探索轨迹。

### 5.7 可学习关注场与边界形成条件

探针事件不是无目标动作，但它的“目标范围”也不应由工程师预写成固定世界切片。

更合适的架构要求是：

- 每次探针会诱发一个**可学习关注场**
- 该关注场会围绕当前活跃对象、关系、时间片形成初始偏置
- 其边界在后续探索中可以被强化、漂移、收缩、扩张或重构

这意味着系统不是在探针发起时就“知道最终边界是什么”，而是在探针历史中逐步学会：

- 当前主要影响了哪一片对象范围
- 哪些关系耦合最稳定
- 哪个时间窗最值得继续关注
- 哪些变化只是邻近扰动，哪些变化可能暴露了新的结构

因此，探针所带的不是固定“目标切片”，而是一个可学习的关注场形成偏置。

### 5.8 学习关注维度条件

系统仍然需要知道“优先学什么”，但这也不应变成新的世界本体轴或人工内容分类。

正确做法是：探针历史逐步在现有 substrate 上形成若干**学习关注维度**，例如：

- 可控性
- 耦合强度
- 延迟
- 稳定性
- 可重复性
- 不确定性降低幅度

这些维度不是 tier 0 新轴，不是语言单位，也不是概念单位。它们只是系统在主动学习中逐步形成的更新偏好，用于决定哪些变化优先进入后续 VPC 更新。

### 5.9 结果边界的可学习分化条件

探针后的变化不能被工程师静态分成“目标结果 / 溢出结果 / 意外结果”。

更符合本架构的写法应是：

- 系统在探索中逐步形成当前关注场的中心区域
- 与中心区域稳定耦合的变化，逐步成为主学习结果
- 位于边缘但反复相关的变化，会改变关注场边界
- 长期超出当前关注场却反复被同类探针带出的变化，会迫使系统扩展或重构边界

因此，“目标”“邻近”“意外”都只是当前学习状态下的暂时区分，而不是永久字段。

### 5.10 短时模式保持与自他比较条件

模仿比一般探索多一层要求：系统必须能把外部模式在短时间内保持住，并把它与自己的输出结果做比较。

这里的“模式”首先不是词义，而是时间曲线、节律结构、声音形态或其他外部连续模式。

模仿的最早形式应被理解为：

- 外部模式进入
- 内部短时保持
- 产生近似输出
- 比较输出与原模式的误差
- 继续逼近

它首先是曲线逼近，不是意义复述。

### 5.11 历史强化与可逆捷径条件

当某类动作-后果耦合、某类关注场边界、或某类模仿路径反复成功时，系统可以逐渐压缩它们，使其更快被调起。

但这些路径必须保持可逆，不能变成不可撤销的先验本体。

否则早期 babbling、早期模仿、早期探索会过早固化成僵硬习惯，反而破坏继续学习的能力。

### 5.12 三个边界结论

第一，早期主动探索先于语言绑定。  
系统先形成动作探针、闭环学习、时序逼近与历史强化，其中一部分模式后来才可能进入语言绑定层。语言层不能反向充当这些行为的前提。

第二，早期模仿先于语义理解。  
系统首先模仿的是外部时间曲线和模式结构，而不是“话语意义”。如果一个设计要求先有内部词义才能开始模仿，那就是倒置了发展顺序。

第三，“主动性”不是单独模块，而是条件满足后的现象名。  
只要系统同时具备持续活动、低成本探针、闭环、时序耦合、可学习关注场、未闭合偏差驱动、precision 重分配和可逆历史强化，外部就会观察到类似“主动”“会试”“会模仿”的现象。反之，不应通过外挂模块制造假主动性。

第四，关注场边界必须被学习，而不是被写死。  
允许预设的只能是边界形成法则与更新约束；不允许预设对象范围、目标范围、结果边界的最终内容。

## 6. 抽象法则与当前 `bionic_v0` cleaned substrate 的映射，以及当前真实缺口

这一章的目的不是评价当前实现“功能够不够”，而是回答：

`现有 cleaned substrate 已经承载了哪些法则，哪些法则只具备雏形，哪些法则在当前还根本没有正式落点。`

### 6.1 已具备正式落点的法则部分

#### 6.1.1 共享持续运行的基底已具备

`viewport`、predictor、slot、relations、reasoning、history 已经构成了一个持续更新的共享态底座。

这意味着“系统不是 request/response 程序”这一前提在工程结构上已经站住。它还不是完整主动性，但已经满足了主动性所需的最低运行背景：系统本身会持续演化，不必等待外部语言命令才存在。

#### 6.1.2 误差驱动更新已具备

当前 substrate 中已经有明确的 predictor / err / precision 风格结构。

这为“未闭合偏差驱动”提供了真实落点。虽然现阶段这个驱动主要服务于感知、关系、推理侧，而不是主动动作探针，但底层范式已经存在。

#### 6.1.3 多时间尺度结构已具备雏形并基本成型

slot 级、relation 级、reasoning 级、reasoning history 级这些层次，已经构成了快层到慢层的基本分化。

这意味着“快速反应、慢速整编、长期痕迹”已经不是空话，而是有具体 substrate 可依托。

#### 6.1.4 历史痕迹与可回溯性已具备部分基础

当前已有 snapshot、observer、history、memory summary。

虽然这还不是完整的 fast-path formation / revocation 机制，但“状态可回看、更新有痕迹、结果能被观察验证”这一点已经具备，这对后续一切主动性、自调整、自修复法则都很关键。

### 6.2 只具备雏形但尚未成为正式法则的部分

#### 6.2.1 精度-资源再分配只具备局部形式，尚未统一为总法则

现在有 attention、precision bias、routing、health 等结构，但它们还没有被统一组织成一套“系统如何在对象、时间尺度、行为通道之间重分配资源”的总法则。

相关零件存在，但缺少一个更高层的统一 contract。

#### 6.2.2 局部失败局部修复只具备工程直觉，尚未被正式定义

当前系统会出现衰减、失活、重算、重新分配，但这还不能算完整的“局部失败局部修复法则”。

它还没有明确回答：

- 什么算局部退化
- 什么时候应优先绕行
- 什么时候应优先降级
- 什么时候应优先重学
- 什么时候应宣布某条路径暂时不可用

#### 6.2.3 可逆捷径只存在于概念层，尚未成为正式 substrate

文档中已经明确允许 `fast-path`，但当前实现还没有一个正式、独立、可回撤的捷径形成机制。

所以“历史强化与可逆捷径法则”目前更多还停留在理论允许和设计方向，而不是代码中的正式层。

#### 6.2.4 语言绑定只是 foundation，不足以承担更高层发展现象

现在的 language binding 只完成了：

- trace substrate
- reversible binding event
- viewport / snapshot / observer 最小暴露

它还不能承接“早期模仿如何过渡到共享表达”的更大问题。

### 6.3 当前仍然缺失正式落点的关键法则

#### 6.3.1 低成本动作探针法则缺失

这是当前最大的缺口之一。

现有 `bionic_v0` 主要是 perception-first substrate。它还没有一个正式的、可学习的、可回读的动作探针层。

没有这个层，主动性只能停留在“内部可能持续活动”，不能真正外显为主动探索。

#### 6.3.2 动作-后果闭环法则缺失

系统现在有感知输入，也有内部更新，但还没有完整的：

`动作输出 -> 世界变化 / 自身变化 -> 感知回流 -> 学习更新`

合同。

没有这条闭环，就不会出现真正意义上的 babbling、试探、模仿、主动验证。

#### 6.3.3 可学习关注场与边界形成法则缺失

当前系统没有一个正式 contract 来回答：

- 探针如何诱发关注场
- 关注场如何围绕对象/关系/时间结构逐步收敛
- 边界何时扩张、收缩、漂移或重构
- 哪些变化会从边缘进入主学习区域

这意味着系统还不能真正“自己学会范围”，只能被动等待工程师解释。

#### 6.3.4 短时模式保持与自他比较法则缺失

模仿要求系统能暂时保持外部模式，并将其与自身输出比较。

当前 substrate 有时序历史，但没有一个专门服务于“外部曲线保持 + 自发输出曲线比较”的正式 contract。

因此模仿在当前架构里仍然只是可讨论的法则方向，不是现成能力。

#### 6.3.5 主动性触发条件缺失统一定义

当前系统没有正式定义：

- 什么情况下系统应自发发起探针
- 什么情况下应保持沉寂
- 什么情况下应继续试
- 什么情况下应停止某条探索路径

主动性目前还没有从“持续运行背景”上升为“可定义的动力学法则”。

#### 6.3.6 自稳 / 自我修复法则缺失统一定义

当前也没有正式 contract 来回答：

- 系统怎样定义自身偏离
- 怎样定义局部退化
- 怎样把退化和普通噪声区分开
- 怎样触发局部补偿而不是整体震荡

所以自我修复、自我调整当前仍是研究主题，而不是已存在能力。

### 6.4 本章判断

基于当前 cleaned substrate，可以做出一个严格而克制的结论：

- 当前系统已经具备研究主动性、自我调整、自我修复的底座条件
- 但尚不具备把这些现象自然生成为稳定外显行为的完整法则闭环
- 因此下一步不应直接实现“主动发声”“主动模仿”“自修复功能”
- 而应优先补齐缺失的底层法则合同
- 尤其是把“边界自己学会”写成正式法则，而不是继续写成程序字段

当前 `bionic_v0` 的正确定位应是：

`它已经是一个足以承载更高层生命式行为法则研究的 cleaned substrate；但它还不是一个已经自然长出主动探索、自我修复、早期模仿的系统。当前缺的是法则闭环，不是功能菜单。`

## 7. 后续子 spec 的拆分原则

这份总 spec 不应直接变成 implementation plan，也不应把所有问题压进一份巨型文档。它的作用是给后续研究立边界，并决定哪些问题必须拆成独立子 spec。

建议按“法则闭环”而不是按“功能名”拆分。后续子 spec 至少应分成 4 类。

### 7.1 内生活动与主动探针法则

主题不是“主动行为功能”，而是：

- 持续内生活动如何维持
- 什么构成低成本探针
- 什么条件下系统发起探针
- 什么条件下停止探针
- 探针如何不把系统拖进无意义躁动

这是主动性的最小动力学闭环。

### 7.2 动作-后果闭环与模仿法则

主题不是“模仿模块”，而是：

- 输出如何重新进入感知
- 动作与后果如何做时序配对
- 外部模式如何短时保持
- 自身输出如何与外部模式比较
- 模仿如何从曲线逼近长出，而不是从语言理解长出

这是早期探索、babbling、模仿的最小闭环。

### 7.3 自稳、自我调整与局部修复法则

主题不是“修复功能”，而是：

- 什么是局部退化
- 什么是整体不稳
- 何时该降级
- 何时该重路由
- 何时该重学
- 历史稳定路径如何被优先回归

这是自我调整与自我修复的最小闭环。

### 7.4 可逆捷径形成与撤销法则

主题不是“技能系统”，而是：

- 什么样的高频成功路径可以压缩
- 快捷路径怎样不僵化
- 怎样局部撤销
- 怎样防止早期错误被固化成假本能

这是主动性、模仿、修复三者都会用到的共用基础法则。

### 7.5 拆分的硬约束

任何子 spec 都必须回答：

- 这条法则落到哪些已有 substrate
- 新增的只是规则，还是新增了新层

如果回答开始变成“需要新器官”“需要新人格核”“需要主动性模块”，就说明已经偏离。

## 8. 开发准入与防偏移禁令

这份总 spec 必须附带比普通功能 spec 更严格的准入规则，否则之后很容易被例子牵着走，重新滑成模块拼装。

### 8.1 禁止从现象名直接造模块

不得因为外部看到“主动性”“模仿”“自我修复”，就在内部新增：

- `initiative_engine`
- `imitation_module`
- `self_repair_system`
- `curiosity_core`
- `motivation_center`

这类命名直接把观察术语误当内部本体。

### 8.2 禁止把高阶现象写成单一原因

主动性、自我修复、自我调整都不得被归因于单个变量、单个阈值或单个器官。

它们必须被解释为多条底层法则共同作用的结果。

### 8.3 禁止把好奇心与探索时机压成少量程序控制数字

不得在理论层把下列复杂结构性现象预先翻译成少量控制数字，再拿这些数字反过来定义系统本体：

- 好奇心
- 探索时机
- 延迟探索
- 背景浮现
- “我现在忙不忙”

若未来工程实现需要数值近似，那也只能是实现阴影，不能反过来规定理论层的真实结构。

### 8.4 禁止跳过动作-后果闭环直接做主动行为

任何“主动行为”实现如果没有明确动作输出、回流感知、时序耦合学习的闭环合同，都视为伪主动性。

### 8.5 禁止预写世界内容边界

允许预设的只能是学习法则、身体法则、更新约束和安全硬边界。

不得由工程师预写：

- 最终对象范围
- 最终目标范围
- 固定结果分类
- 固定重要性地图
- 固定探针学习内容

这些边界若需要存在，必须通过探索历史逐步形成，并且保持可漂移、可修正、可重构。

### 8.6 禁止把学习关注维度误写成本体新轴

主动探针中的“学习关注维度”只能是更新优先级与学习偏置，不能写成：

- 新 tier 0 轴
- 新语言轴
- 新概念轴
- 新身份轴

它们是学习法则中的偏置，不是世界本体元素。

### 8.7 禁止跳过曲线逼近直接做模仿语义

任何“模仿”实现如果直接从词、句、标签、token 开始，而不是先从外部模式保持、自他比较、时序逼近开始，都违反发展顺序。

### 8.8 禁止把修复理解为恢复到人工预设模板

自我修复不得等同于“回到某个硬编码默认状态”。

真正允许的只能是：

- 局部补偿
- 局部绕行
- 降级运行
- 再学习
- 历史稳定路径回归

而不是简单 reset 成工程师预设的理想形态。

### 8.9 禁止让语言层解释主动性与修复

语言层只能在后期为已有行为模式提供 binding，不得充当主动行为、自我修复、自我调整的生成根源。

### 8.10 禁止引入新的本体身份词

凡是使用 `self`、`agency`、`will`、`intention`、`repair`、`motivation`、`curiosity` 等词，都必须明确：

- 这是外部观察术语还是内部本体术语
- 如果是内部工程术语，它只是索引、统计还是规则名
- 它为什么不构成新的 ontology layer

---

## 9. 收束结论

后续开发的正确方向，不是把“主动”“模仿”“修复”做成功能，而是逐步补齐那些在 cleaned substrate 上尚未闭环的底层法则。

只有当法则闭环足够完整时，这些现象才有资格被期待自然出现。

本 spec 因而要求后续研究始终遵守以下总原则：

`先发现法则，再解释现象；先补闭环，再期待行为；先守住本体边界，再讨论外部观察名称。`
