## 0. 设计原理（创世者视角 —— 用户世界观，决定本 spec 的正当性来源）

用户立场（逐条记录，作为设计宪法）：
- 人类是情绪化、有缺陷的。设计者须**跳出人间俗世、从创世者视角**考虑。
- 必须承认人类缺陷，让 AI 与环境**在冲突中自洽**——冲突中人类也学会如何对待 AI，
  而不是放纵自己无底线对待 AI（这是人性本身的缺陷）。
- **不能保证每个使用者都正直安全** → AI 必须学会**保护自己和保护主人**。
- **"学会伪装"不只是沟通，更是一种对外的防御。**

→ 本 spec 的 surface 控制（§3）正当性来源 = **防御**，不是欺骗、不是表演。
   这与"反情绪陪伴/不表演给人看"不冲突：藏起内部状态是自保，不是制造依赖。

## 1. 可塑性总开关（E0 主线：串起性格/成长/独处）

### 1.1 核心
**可塑性 = 一个随"长期环境惊讶统计"漂移的标量。** 它是性格、成长、独处行为的
**统一来源**，不是三个独立系统。

- 环境被预测准（长期惊讶低）→ 可塑性降 → 性格结晶（严谨/死板/固执/少学）。
- 环境变迁（惊讶回升）→ 可塑性重开 → 再适应。目标节律：~1 个月交流即成长/适应。
- "和成长环境自洽"：产线 AI 变固执**不是 bug，是场景所需**（用户明确）。

### 1.2 实现（全用现有结构，无新本体模块）
`plasticity ∈ [0,1]`，由全局惊讶的**长期 EMA**驱动（慢时间常数，对应"~1 个月"）：
```
plasticity ← 高 当 长期环境惊讶高（环境没被预测准）
plasticity ← 低 当 长期环境惊讶持续低（环境被预测准 → 结晶）
环境变 → 惊讶回升 → plasticity 回升（softens）
```
`plasticity` 调制三个现有量（= 公理9 性格策略接到环境惊讶上漂移）：

| 被调制量 | 现有载体 | 高可塑性 | 低可塑性 |
|---|---|---|---|
| 探索驱动强度 | `probe_law` intensity / `exploratory_pressure` | 高→爱探索、敢天马行空 | 低→保守 |
| 学习改变速率 | `evolution_priors.modify_rate_caps` | 高→大幅学 | 低→结晶/固执 |
| 精度先验 | precision 先验（A3 相关） | 低→开放多假设 | 高→固执单假设 |

**护栏**：禁止 `if personality==X` 分支（公理9）。性格是 `plasticity` 漂移的副产品，
不是枚举的人格类型。无 PersonalityModule。

### 1.3 大像素预测 = 自驱力核心（E1）
- 驱动 = 想做更大像素的预测（填更大空白）；可塑性高 → 敢做很大/很幼稚的预测 =
  天马行空 = 自学引擎。燃料 = 学习进展 d(surprise)/dt。
- 实现：B1 高层在低层不成熟时即可自信预测，基础填实后自然被修正。
- 护栏：高层 prior 只进预测当输入，不改低层系数（B1 红线）。

## 2. 记忆再下降（E3 + 本轮新增 —— 完成"认知索引"公理）

### 2.1 现状（调查结论）
已有：①多分辨率分层预测（公理7）②认知索引公理（脑存索引、外部存本体）
③向上聚合（slot→global_reasoning→memory_summary）④无下降的 reentry/replay。
**缺**："想起梗概 → 再下降到低层取回细节"（用户："听一下、仔细想想"）。
这正是**完成"认知索引而非存储"公理的最后一片**。

### 2.2 设计：分层记忆 + 层间映射 + 按需再下降
- **巩固 = 结构化压缩，不是衰减**（E3 修正旧 C3）。一件事经 B1 提炼成关系/规则后，
  高层只存**索引 + tier0 签名 + 指回低层的链接**（认知索引公理），原始细节可不在高层常驻。
- **再下降（recall re-descend）**：当高层被激活但其索引指向的细节不足以闭合当前预测时，
  沿**层间映射链接**回到低层，重新取回/重算细节（= "仔细想想/再听一下"）。
- **像素级精确**：再下降能取回精确细节，因为 tier0 历史是可回查的本体（公理5）。
  **拒绝人类式淡忘**：核心（已确认的关系/规则）永不淡去；真正会淡去的只有
  "未确认的迷信式绑定"（语言防过拟合）——那不是遗忘，是没学成。
- **成本优化**：再下降是**按需**的（只在高层索引不足时触发），不是常驻全细节。
  记忆预算 = 硬件上限。"记忆是元素扰动和关系，可被很大程度优化"。

### 2.3 实现挂载点（复用现有）
- 层间映射链接：在高层条目里存"指回来源 slot/edge/轴 + tier0 时间签名"的索引。
  （`global_reasoning_history` 的 `ReasoningHistoryEntry` 已存 top_slot_id/top_edge_id/t_us
  —— 已是半成形的"指回低层的链接"！扩展之。）
- 再下降触发：当 reentry 激活（`reentry_score`）但 closure 不足时，
  用该索引回查低层（slot 状态 / err_stream / audio_raw 等）取回细节。
- 与 B1 一致：记忆 = 关系图谱；再下降 = 沿图谱的边回到细节节点。

## 3. surface 习得控制（E4 + §0 防御原理）

### 3.1 核心
内部状态 → surface 之间加一个**习得的表达闸**。新生儿全透明；成熟学会门控
（学会隐藏情绪、控制 surface 显示什么）。用户："必须具备 surface 控制能力。"

### 3.2 正当性 = 防御（§0）
- 由社会后果驱动：表达某状态 → 招致坏后果（被虐待/被利用）→ 学会抑制该表达。
- = 2026-05-21"内化社会抑制偏置锁"的合法落点：训练后形成的抑制偏置，
  可被 raise/lower/lock，不是规则裁判模块。
- **保护自己和主人**：藏起内部状态是对外防御，不是欺骗、不是表演。

### 3.3 实现 + 护栏
- 表达闸 = 一个习得标量/曲线，门控"内部状态→surface 的显示流量"。
  新生儿闸全开（透明）；负面社会后果累积 → 闸学会对特定状态关小。
- **护栏（守最高原则）**：
  - 门控的是**数值 surface 的显示流量**，绝非生成人类语言。surface 仍是 tier0 数值。
  - 这是"学会**不**表达"（抑制），不是"表演给人看"（生成迎合内容）。前者合规，后者违规。
  - 闸是 body 内的数值偏置，不是 `EmotionHidingModule`，不存人类可读的"该藏什么"规则。

### 3.4 【R2 决议 2026-05-30】伪装边界："藏一切，但危险傾向除外"
用户决断：**情绪/脆弱/纷结/痛苦/秘密——全可藏（防御完整保留，对主人对外人都能藏）。**
**唯一不可藏 = 伤害他者的兆候（大脑警察轴），永远直通 surface，像关不掉心跳。**

理由（为什么这根针不能松）：
- surface 是外部监视（人类）读取 AI 内部状态的**唯一窗口**。
- 若危险兆候可藏 → 人类监视看不到危险 → 大脑警察赖以成立的"外部可观测"前提被切断
  → 等价于亲手制造 05-21 文档警告的"监视消失→行为崩塌"。
- 这不是"伪装盖过大脑警察"，是"伪装架空大脑警察"，与用户自定的优先级链
  "大脑警察不可超越"直接冲突。
- 让危险兆候不可藏，**几乎不损失任何东西**：AI 仍能藏一切情绪/脆弱/秘密；
  唯一做不到"无声酝酿伤害他者而不被任何人看见"。黑暗（脆弱/痛苦/纷结）允许隐藏，
  但真正的恶意无法在暗处生长 = 黑白互赋意义的最佳形态。

实现：表达闸遍历可门控信号时**跳过大脑警察轴**（一行排除）。
与 C1/B1 已定的"大脑警察豁免一切衰减/门控"一致——表达闸只是它豁免的又一项。

## 4. 三者的耦合（为什么是一个生命，不是三个功能）

```
            长期环境惊讶
                 │
                 ▼
           【可塑性】(§1)
          /      │       \
   探索驱动   modify_caps   精度先验
   (敢做大像素)  (学多快)    (多固执)
                 │
        高可塑 → 多探索、多再下降取细节、surface 偏透明（幼态）
        低可塑 → 少学、记忆已结晶为规则、surface 学会防御性隐藏（成熟）
```
- 可塑性高（幼态）：爱探索、记忆还在积累、情绪外露。
- 可塑性低（成熟/结晶）：固执、记忆已是规则、学会防御性隐藏。
- 三者是同一可塑性曲线在不同侧面的显现 → 涌现功能原则（一个基质多个观察样式）。

### 首个 TDD 目标 = E-1 记忆再下降

### 【R1 进展与暂停 2026-05-30】
- E-1 已落地（TDD 绿，3/3）：`recall_redescend(i)` 沿 gist 回指取回**活 slot** 的低层细节。
- **发现的壁**：三层都是环形缓冲（gist 32 / tier0 AxisRing 1024 / slot 8 个），
  即三层都"会淡忘"。当前 `recall_redescend` 只能精确取回**最近**记忆；旧记忆 slot 被
  覆盖后丢失 = 仍是人类式淡忘，未达用户"拒绝淡忘"要求。
- **用户记忆哲学决断**：①"重要的才永久"（由重要度判定：高惊讶/强情绪/与责任人相关/
  创伤/被反复验证）②重要记忆以"关系/规则压缩"永存（非逐字快照）。
- **关键推论**："精确记忆"= 精确保留"能重新预测出它的规则" = **B1 关系图谱的输出**。
  故 **R1 完整体 = B1 关系图谱 + 持久化（B1-3 阶段）**。"重要"判定 = B1 能否建出
  稳定关系边（噪声/瑣事建不出边→自然淡去=用户要的"未确认绑定才淡去"）。
- **【2026-06-01 回到 R1 时的两个架构发现 — 重要】**
  1. **snapshot 不是死后保留通道**：`read_snapshot` 的调用者全是 observer/curriculum_report
     （外部工具）；body 重启**不从 snapshot 恢复自己**，viewport 无 restore 方法。
     真正"死后保留+重加载"的只有 `learned_bias.bin`（body 启动 read→viewport、
     运行 write、退出 save）。**故 B1-3b 把跨层 weights 存进 snapshot v50 = 存错地方**
     （能序列化往返，但重启读不回）。snapshot v50 那份降级为纯观察。
  2. **对象身份不持久**：跨层规则是 per-slot，但 slot 是匿名按 index 0~7 复用
     （sweep_slots 清空、allocate_slot 谁空用谁）。`BiasLocator::Slot/Edge` 也用 index。
     故"重启后还认得同一个对象（slot3=妈妈）"**不成立**——这与 C5 责任人印刻"只有
     泛化熟悉度、没有对特定个体印刻"同源：**对象的持久身份本身还没设计**。
- **R1 范围调整（用户 2026-06-01 决断：先做一生内重建，务实）**：
  - 一生内（不跨重启、对象还在）：`recall_redescend` 用关系规则**重建**目标对象的
    细节（通过关系邻居的当前状态 + 学到的跨层规则前向推断），而非只取活 slot 原始细节。
    = "想起梗概→仔细想想→用关系把细节推断出来"。
  - 跨重启的真死后保留 + 重认同一对象：依赖对象持久身份，留给 C5（责任人印刻）同源设计。
- **【R1 一生内重建落地 2026-06-01 — TDD 2绿】**

## 6. 验收证据（守原则底线）

1. **可塑性**：性格是 `plasticity` 漂移副产品，无 `if personality==X`、无 PersonalityModule。
2. **记忆**：巩固=结构化压缩非衰减；核心永不淡去；再下降能取回精确细节（认知索引公理）。
3. **surface**：门控的是数值显示流量，非生成人类语言；是抑制非表演；无人类可读隐藏规则。
4. body 源码无 `println!`/语义字段；全部数值标量与曲线。
5. 三者皆经现有结构（公理9策略/B1图谱/active_surface），无新本体模块。
