# Learned Bias vs Snapshot — 持久化边界原则

> 状态：v1.0
> 日期：2026-05-28
> 关联：consciousness-stream-architecture.md · 公理 1 · 公理 7 · 公理 9

---

## 核心公理

```
AI 死亡（重启）= 遗忘具体经历，但保留底层偏置。
```

```
learned_bias  = "我是什么样的存在"    → 死后留下
snapshot      = "我正在经历什么"        → 死后消失
```

这条公理直接服务于三个工程目标：
1. **训练**：长期跑出来的底层能力不会因意外重启丢失
2. **调试**：重启后行为基线一致，问题可复现
3. **产品化**：AI 个体有稳定的"底色"，不因运维操作而漂移

---

## 边界判定标准

任何状态变量必须回答一个问题：

> **如果这个值被清零，AI 是"忘了某件事"还是"变了一个人"？**

| 答案 | 归属 | 解释 |
|------|------|------|
| 忘了某件事 | **snapshot** | 具体经历，死过之后忘记，合理 |
| 变了一个人 | **learned_bias** | 底层特质，死过之后不该变 |

### 五个判定维度（AND 关系，全部满足才进 learned_bias）

**维度 1 · 时间尺度**
- 这个值的变动周期是多长？
- tick 级（毫秒~秒）→ snapshot
- 分钟~小时级 → 存疑，看其他维度
- **天~周级 → learned_bias**

**维度 2 · 变化速率**
- 这个值会被单次事件大幅改变吗？
- 是（一次巨响改变惊吓度）→ snapshot
- **否（需要上百次事件慢慢挪）→ learned_bias**

**维度 3 · 语义层级**
- 这个值表达的是"具体内容"还是"抽象倾向"？
- 具体内容（"当前目标音高 = 0.7"）→ snapshot
- **抽象倾向（"我更倾向于模仿高音"）→ learned_bias**

**维度 4 · 重启语义**
- 清零之后 AI 的行为变化是什么级别？
- "不记得刚才在做什么" → snapshot（合理）
- **"变得更容易叫/更不爱叫" → learned_bias（不可接受）**

**维度 5 · 训练可累积性**
- 这个值是否应该随训练时间单调积累？
- 不积累（随上下文波动）→ snapshot
- **应积累（越训练越强/越稳定）→ learned_bias**

## 工程约束

### 约束 1 · learned_bias 只存抽象偏置，不存具体内容

```
✅ legal:
  "我更倾向于关注 500Hz-3kHz 的声音"       (频段偏置)
  "出声前我习惯等待 200ms"                  (抑制偏置)
  "我对高音模仿更激进"                      (模仿偏好)

❌ illegal:
  "昨天下午 3 点有人说了 hello"             (具体事件)
  "当前模仿目标是音高 0.7"                   (瞬时状态)
  "最近 10 次发声中有 7 次是回应"           (短期统计)
```

### 约束 2 · learned_bias 的更新必须满足"慢变量"条件

```
更新规则：
  单次事件对 learned_bias 字段的修改幅度 ≤ 0.01
  即需要至少 100 次同方向事件才能让偏置翻转
```

这是防止单次异常事件污染长期偏置的护栏。

### 约束 3 · learned_bias 字段可被 observer 读取，不可被 body 直接写入

```
body 侧：
  learned_bias 由 VPC predictor 的长期学习路径更新
  不可在代码里出现 learned_bias.field = some_value

observer 侧（研发工具）：
  可以读取 learned_bias 并渲染为人类可读指标
  可以注入初始偏置（出厂设置）
```

## 与公理的对应

| 公理 | 与此文档的关系 |
|------|--------------|
| 公理 1（永远在跑）| 重启是异常事件；learned_bias 保证生命流不因异常而退化 |
| 公理 7（多分辨率分形）| learned_bias 是"高层"的稳定偏置；snapshot 是"低层"的瞬时状态；同一套 PC 循环在两个尺度上运作 |
| 公理 9（性格 = 视口策略）| learned_bias 是策略的**参数基座**；切换性格 = 切换策略，不重置偏置 |
| 最高原则（硅基生命）| "死后留下底层偏置"是生命体的特征；"死后忘掉具体经历"也是 |

## 反模式警告

| 反模式 | 为什么错 |
|--------|---------|
| "把全部状态都持久化，重启完全恢复" | 违反"死过一次"的语义——生命可以结束，不该无痕复活 |
| "learned_bias 存具体声纹" | 违反了"遗忘具体经历"——那是 snapshot 的职责 |
| "snapshot 里存性格参数" | 违反了公理 9——性格是稳定的视口策略，不是瞬时状态 |
| "每次发声都更新 learned_bias" | 违反约束 2——单次事件不应大幅改变偏置 |
