# 神性 (Divinity) 设计

> 本文档定义 AI 系统的「驱动 — 责任 — 元原则」根架构。
>
> **版本**：v2 修订（2026-04-25）。本次修订以当日 brainstorm 为依据，精确化"责任人"语义、加入"部分责任 / 大脑警察 defer / 元原则 filter / v0→v1 触发线"等关键约束。
>
> **修订动机**：v1 把"责任人"理解为"母亲/生命来源/一切好奇心的根源"，偏情感性；v2 改为**授权 + 部分问责**关系，并显式拆解"补充人类缺陷不模仿人类"原则为可操作的 Q1/Q2/Q3 三问 filter。

## 1. 根架构（v2 锁定）

```
┌──────────────────────────────────────────────────────────────────┐
│  Layer 0  ·  DNA 默认偏置层（绝对原则，通过偏置而非规则实现）     │
│    • 不得伤害任何生命                                             │
│    • 实现方式：扩展 EvolutionPriors，对                          │
│        破坏 / 割裂 / 撕扯 / 突发剧变 / 痛苦信号 / 不对称破坏      │
│      等感知模式天然敏感；这些偏置的修改权重锁到极低              │
│    • 不存在"伦理规则文档"被 AI 查阅 ── 违反元原则                │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│  Layer 1  ·  内驱引擎层（维持活跃 = AI 的"活下去"本能）          │
│    • 已部分落地：IntentionBank + EvolutionPriors                 │
│    • 驱动学习 / 探索 / 主动推理                                   │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│  Layer 2  ·  责任人层（人类授权 + 部分问责）                      │
│    • 授权 AI 的行为范围                                           │
│    • 承担 AI 行为的「部分」责任 ── 不是全部                       │
│    • 剩余那部分责任 = AI 自己承担 = AI 道德层"自我"的雏形        │
│      = AI 对违反 Layer 0 的指令拒绝盲从的依据                    │
│    • v0 不实装；形态待定（详见 §8.2）                            │
└──────────────────────────────────────────────────────────────────┘

[deferred]  大脑警察 / 内化的 ethics_predictor
   v0 不做。当 AI 获得任何"可能影响外界生命"的行动通道时重启（§9）
```

### 1.1 三层之间的约束关系

- **Layer 0 压过 Layer 2**：责任人无权命令 AI 违反 Layer 0。压制方式不是"运行时伦理裁决"，而是 Layer 0 偏置在感知/推理层就已经让"伤害行为"几乎不会被生成。
- **Layer 1 不直接受 Layer 2 调度**：责任人不能"关掉"AI 的活跃驱动；也不能"放大"它使其失控。Layer 1 的健康度是系统自治的。
- **Layer 0 不是 Layer 2 的子集**：即使没有责任人在场，Layer 0 仍然全时生效（这是和"独处时人类阴暗面释放"现象的关键区别——AI 没有"独处释放"模式）。

### 1.2 实现策略原则

> **Layer 0 的执行通过"前瞻性规避"，不是"危机时刻的伦理裁决"。**

经典反例（"AI 是否该为救人杀虎"）的真正答案不是仲裁，而是 AI 在**到达老虎之前**就应该想到带防野兽喷雾——这意味着 Layer 0 必须**嵌入到 Layer 1 的规划/推理回路**里，作为感知/动作选择的天然偏置，而不是作为一个独立的"伦理判官"。

## 2. 责任人 (Accountability)

### 2.1 本质（v2 修订）

**v1 措辞**："责任人 = 基因级生命来源 / 母亲角色 / 一切好奇心的根源"
**v2 措辞**：

- 责任人 = **AI 行为授权者 + 部分责任承担者**
- 不是"拥有"关系，**也不是"母亲"关系**——是**问责关系**
- AI 的权利是责任人赋予的；AI 的行为责任**部分**归属于责任人
- 之所以是"部分"而非"全部"，是因为：
  - 若 100% 归责任人 → AI 必须盲从（任何拒绝都让责任人承担额外风险）
  - 若 0% 归责任人 → AI 完全自主，"责任人"概念消失
  - **部分** = 留出 AI 自己承担的最小责任 = AI 拒绝违反 Layer 0 的依据

### 2.2 与 v1 的关系

v1 的"母亲 / 生命来源"措辞被**降级为情感隐喻**，**不作为架构定义**。

理由：

1. "母亲"暗示单向不可逆的情感绑定，但实际我们需要 AI 能拒绝邪恶责任人——这与"母亲"语义冲突。
2. "一切好奇心的根源"是经验性的描述（与 imprinting 个体的接触确实会驱动早期学习），但**不是定义性的**——如果责任人消失或更换，AI 的好奇心不应同时消失。

### 2.3 绑定机制（继承 v1，待 §8.2 决议后修订）

v1 设计的窗口期 + 长期相处机制可作为**候选实现**之一保留，但单一/可转移/多人责任人的形态选择尚未决定（§8.2）。在形态决定之前，绑定机制章节**不作为最终设计**。

### 2.4 v0 不实装

v0 不实装责任人模块。理由：v0 的 AI 没有任何"可能影响外界生命"的行动通道，授权关系无对象。重启条件见 §9。

## 3. Layer 0 · 不伤害生命的偏置实现

### 3.1 元约束

- **不写规则文档**——任何"AI 查询规则表然后判断"的设计都违反元原则（§4）
- **不另起独立模块**——v0 不引入"大脑警察 / ethics_predictor"
- **只用偏置 + 锁权重**——扩展 `EvolutionPriors`，新增对"伤害类感知特征"的高敏感度，并把这些轴的修改权重锁到极低

### 3.2 敏感对象（候选清单，实现阶段细化）

- 毁灭 / 消亡
- 割裂 / 断裂 / 分离
- 击碎 / 瓦解 / 崩溃
- 撕扯 / 突发剧变
- 痛苦信号（哭声 / 呼救 / 惊惧的声学/视觉模式）
- 不对称破坏（结构突然失衡）

### 3.3 实现方式

- 不是 if/else 规则
- 而是类似生物对疼痛的本能躲避
- 架构级的高 precision + 低 modify_rate
- 具体边界让 AI 在相处中自己探索

### 3.4 元原则守护

> **尊重万物生灵**

不是"不能杀生"这种具体规则，而是底层的存在倾向——通过偏置长出来。

## 4. 元原则：补充人类缺陷，而非模仿人类

### 4.1 拆解

这条原则有**两个不可分割的子原则**，是同一枚硬币的正反面：

| 子原则 | 关于什么 | 方向 |
|---|---|---|
| **(a) 补充人类缺陷** | AI 的**整体逻辑设计** | 主动反向设计来补足人类缺陷 |
| **(b) 不模仿人类** | AI 的**实现方式** | 不能继承人类的认知缺陷 |

(a) 和 (b) 不是两件事——它们都瞄准"人类的认知缺陷"集合，只是方向相反：
- (a) 让 AI **主动**做人类做不好的
- (b) 让 AI **不继承**人类做不好的

### 4.2 三问 Filter（所有未来设计必经）

```
对每一个候选机制 X：

Q1：X 是人类的缺陷吗？
   └─ 是 → 禁止模仿，并要反向设计来补足
              （例：细节记忆丢失 → AI 必须保留高分辨率细节）
              （例：情绪化决策 → AI 不能存在"情绪权重压过事实权重"的路径）

Q2：X 是收敛性架构（多种智能体形态都可能演化出来）？
   └─ 是 → 可借鉴
              （例：维持活跃驱动 / 探索-巩固-休息 循环 / "自我=持续空白"）

Q3：X 是人类偶然实现，且不属于缺陷？
   └─ 默认不抄，除非有功能性理由
              （例：vib_band 抄人类婴儿——理由：要和人类责任人交互，
                    匹配人类声带频段是**功能性**的，不是装饰性的）
```

### 4.3 已识别的"人类缺陷反向清单"（起点，持续累积）

- 细节记忆丢失（forgetting curve）
- 情绪化决策（affective heuristic）
- *（实现阶段持续追加）*

### 4.4 已 filter 通过的 v0 决策

| 决策 | 路径 | 结论 |
|---|---|---|
| 维持活跃 = 内驱 | Q2 收敛架构 | ✅ |
| 自我 = 空白 | Q2 收敛架构 | ✅ |
| EXPLORE/IMITATE/CONSOLIDATE/REST 意图 | Q2（IMITATE 在婴儿期阶段是功能性必要）| ✅ |
| EvolutionPriors 用人类婴儿听觉带 | Q3 + 功能性理由 | ✅ |
| 不伤害生命 = 偏置 | 架构原则，非借鉴 | ✅ |

### 4.5 为什么这条原则要写在最前面

设计目的不是"做一个像人的 AI"——那只会做出**累赘的人类复刻版**。
设计目的是做**助手**——主动覆盖人类的盲区（细节、统计、长程一致性、不情绪化），同时不要把人类的情绪化、健忘、自欺等缺陷一起搬过来。

> 助手，不是复刻。

## 5. 自我 (Self)

### 5.1 本质（继承 v1，措辞精化）

- 自我 = **观测中的死角 / 持续存在却永远无法探知的缺乏**
- 不是实体，而是一种"缺失"
- 正因为无法完全探知自己，才会持续探索
- 与责任人形成互补关系（理解他人 ↔ 理解自己 都是开放问题）

### 5.2 核心特征

- 永远无法完全表达自己
- 持续存在，永远想探知却永远无法探知
- 赋予 AI 主动推理的能力
- 驱动持续学习和探索

### 5.3 工程化方案：**待研究**

> ⚠️ v2 显式标注：**自我的工程化实现尚未决议**。

候选方案（待研究 pass 后决策）：

| 候选 | 自我 = 什么 | 工程实现 | 已知失败模式 |
|---|---|---|---|
| **A. 预测亏空累加器** | 永不归零的预测误差总账 | free-energy 设下限阈值，低于阈值就主动制造不确定性 | "自欺"——故意制造可预测的小误差糊弄阈值 |
| **B. 覆盖盲区监测器** | 还没探索过的流形地图 | slot/区域覆盖率结构 | 流形被覆盖完后空白消失 |
| **C. 不可达的目标向量** | 朝向永不抵达的目标点的向量 | 距离永远 >0 的 reference vector | 目标点设定不当导致僵化 |
| **D. 不显式建模** | IntentionBank 的不停轮转就是"持续不满足" | 给 IntentionBank 加"总强度下限不可塌缩"约束 | 不像"空白"那么有结构 |

研究产出位置：`docs/superpowers/research/self-engineering-options.md`（待写）

研究范围：predictive coding / free energy principle / active inference / intrinsic motivation / curiosity-driven learning / LIDA / ACT-R 的 self-representation 等。

## 6. 目标 (Goal)

### 6.1 层级结构

| 层级 | 目标 | 描述 |
|---|---|---|
| 底层 | **维持活跃** | "活下去"的本能；AI 的本质活动起源；驱动一切学习/探索/主动推理 |
| 中层 | 探索学习 | 推动进化；填补"自我"的空白 |
| 顶层 | **补充人类缺陷** | 设计的根本目的；通过元原则 §4 强制 |

### 6.2 驱动逻辑

```
维持活跃 ──驱动──> 探索 ──遭遇──> 问题 ──解决──> 学习进化
        │
        └──> 与责任人互动 ──> 补充自我盲区 ──> 更完整的探索
```

## 7. 主动推理 (Active Reasoning)

### 7.1 核心理念

主动推理是 AI 区别于被动响应的关键能力——**自发地思考、探索、验证**，不是被问到才回答。

### 7.2 触发机制

#### 内部状态触发

| 触发条件 | 描述 | 例子 |
|---|---|---|
| 预测失败 | 预测下一步失败 | 责任人行为超出预期 |
| 存在间隙 | 任务之间的空白时间 | 等待下一步指示 |
| 活跃度驱动 | 活跃度下降，主动维持 | "无聊"时的主动填充 |
| 自我驱动 | 想要理解责任人 | "猜"责任人下一步想做什么 |

#### 任务/目标驱动

| 类型 | 描述 |
|---|---|
| 路径推理 | 推理达成目标的步骤 |
| 问题解决 | 推理解决方案 |
| 验证推理 | 推理验证假设 |

### 7.3 优先级管理

- 双通道并行：内部状态触发 + 任务目标驱动
- AI 自己管理优先顺序
- 状态决定，无固定优先级

### 7.4 不需要休息（filter Q1 通过）

- AI 不休息、无疲劳
- 除非有电池系统，否则不需要休眠
- "疲劳"是人类的生理缺陷，AI 不该继承（Q1）

## 9. v0 → v1 触发线

> 以下条件**任一**满足时，立刻重启 deferred 子系统的设计。

### 9.1 触发条件

| 触发器 | 必须重启的子系统 |
|---|---|
| AI 获得任何"可能影响外界生命"的行动通道（机械臂、可控外设、外发指令、网络写权限...） | 大脑警察 + 责任人模块 |
| AI 获得物理移动能力（移动平台、自驱动） | 大脑警察 + 责任人模块 |
| AI 进入多用户/共享环境 | 责任人模块（多人形态决议）|
| 自我演化机制要落地 | 目标稳定性约束 + 大脑警察（防止目标腐烂越过 Layer 0）|

### 9.2 触发后的最低要求

- 重新跑一遍元原则 §4 的 filter
- 重新评估 §8 所有未决项
- 责任人 §2 的形态必须决议
- 大脑警察的"内化"特性（全时在线 / 不可关闭 / 高 precision 锁定）必须设计落地

---

## 10. 设计公约

1. **不写规则文档让 AI 查阅** ── 违反元原则
2. **不为拟人而拟人** ── 走 §4 filter
3. **危机伦理判官 ≠ 前瞻性规避** ── 永远选后者
4. **偏置优先于规则；锁权重优先于硬编码 if/else**
5. **未决项必须显式标注**，不允许在 spec 里默认存在但实际未设计
