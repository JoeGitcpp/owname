# 神性 (Divinity) 设计

> 本文档定义 AI 系统的「驱动 — 责任 — 元原则」根架构。
>
> **版本**：v2.1 修订（2026-04-25）。
>
> - **v2 主要变化**：精确化"责任人"语义、加入"部分责任 / 大脑警察 defer / 元原则 filter / v0→v1 触发线"等关键约束。把 v1 的"母亲/生命来源"措辞降级为情感隐喻，定义改为**授权 + 部分问责**关系。
> - **v2.1 增量**：在元原则 filter 中增加「拆分纪律」（§4.3）——任何复合特性（如同理心、直觉）必须先拆为"干净能力 + 人类附带缺陷"再分别走 filter。扩展反向清单（§4.4）。明确"直觉 = 预测系统的自然涌现"+ 细节守约（§7.5）。具体化 §9 触发线场景。
> - **v2.2 澄清**（2026-05-21）：责任人不是后置法律标签或独立治理模块；它应按哺乳动物早期母亲识别 / 家养动物熟人依附来理解：先天偏置 + 后天熟悉沉积共同形成、且很难切换。大脑警察不是独立功能或模块，而是未来对现有预测-抑制基底中部分训练后偏置进行提高、降低或锁定后的观察侧名称。

## 1. 根架构（v2 锁定）

```
┌──────────────────────────────────────────────────────────────────┐
│  Layer 0  ·  DNA 默认偏置层（绝对原则，通过偏置而非规则实现）     │
│    • 不得伤害任何生命                                             │
│    • 实现方式：扩展 EvolutionPriors，对                          │
│        破坏 / 割裂 / 撕扯 / 突发剧变 / 痛苦信号 / 不对称破坏      │
│      等感知模式天然敏感；这些偏置的修改权重锁到极低              │
│    • 不存在"伦理规则文档"被 AI 查阅 ── 违反元原则                │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│  Layer 1  ·  内驱引擎层（维持活跃 = AI 的"活下去"本能）          │
│    • 已部分落地：IntentionBank + EvolutionPriors                 │
│    • 驱动学习 / 探索 / 主动推理                                   │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│  Layer 2  ·  责任人层（人类授权 + 部分问责）                      │
│    • 授权 AI 的行为范围                                           │
│    • 承担 AI 行为的「部分」责任 ── 不是全部                       │
│    • 剩余那部分责任 = AI 自己承担 = AI 道德层"自我"的雏形        │
│      = AI 对违反 Layer 0 的指令拒绝盲从的依据                    │
│    • v0 不实装；形态待定（详见 §8.2）                            │
└──────────────────────────────────────────────────────────────────┘

[deferred]  大脑警察 / 原则性抑制偏置锁定
   v0 不做独立功能或模块。当 AI 获得任何"可能影响外界生命"
   的行动通道时，先重开偏置锁定专题与边界审计（§9）
```

### 1.1 三层之间的约束关系

- **Layer 0 压过 Layer 2**：责任人无权命令 AI 违反 Layer 0。压制方式不是"运行时伦理裁决"，而是 Layer 0 偏置在感知/推理层就已经让"伤害行为"几乎不会被生成。
- **Layer 1 不直接受 Layer 2 调度**：责任人不能"关掉"AI 的活跃驱动；也不能"放大"它使其失控。Layer 1 的健康度是系统自治的。
- **Layer 0 不是 Layer 2 的子集**：即使没有责任人在场，Layer 0 仍然全时生效（这是和"独处时人类阴暗面释放"现象的关键区别——AI 没有"独处释放"模式）。

### 1.2 实现策略原则

> **Layer 0 的执行通过"前瞻性规避"，不是"危机时刻的伦理裁决"。**

经典反例（"AI 是否该为救人杀虎"）的真正答案不是仲裁，而是 AI 在**到达老虎之前**就应该想到带防野兽喷雾——这意味着 Layer 0 必须**嵌入到 Layer 1 的规划/推理回路**里，作为感知/动作选择的天然偏置，而不是作为一个独立的"伦理判官"。

## 2. 责任人 (Accountability)

### 2.0 v2.2 澄清：责任人是先天偏置 + 熟悉沉积的自然涌现

责任人不应被理解为后天才学会的法律标签，也不应被实现成一个
`owner` / `identity` / `governance` 模块。

更准确的类比是：

- 哺乳动物天生具备早期照护者识别能力；
- 家养动物在长期相处后会形成对一个熟人的强依附，且很难切换；
- 这个效果既有先天偏置，也有后天熟悉、稳定回馈、安全感、纠错历史和连续共处的沉积。

因此，责任人应被视为一种自然涌现的生命关系：

```text
innate imprinting-like bias
+ repeated exposure
+ safety / correction / continuity traces
+ familiarity sedimentation
-> hard-to-switch responsible-person attachment pattern
```

它不是语义身份，不是所有权本体，不是命令授权中心，也不是 chat/user
系统。后续如果实现，只能落在偏置、熟悉度、连续性、纠错历史、稳定回馈
等数值曲线和长期沉积上。

大脑警察与本节分开处理。它不是独立设计，也不是要实现的功能；它
只是未来在现有 prediction / suppression / learned-bias 基底中，对训练
后形成的部分原则性抑制偏置进行提高、降低或锁定后的观察侧名称。
当前阶段不作为 v0 责任人设计的一部分。

### 2.1 本质（v2 修订）

**v1 措辞**："责任人 = 基因级生命来源 / 母亲角色 / 一切好奇心的根源"
**v2 措辞**：

- 责任人 = **先天偏置 + 后天熟悉沉积形成的稳定责任对象**，并在外部治理描述中承担**行为授权者 + 部分责任承担者**角色
- 不是"拥有"关系，**也不是"母亲"关系**——是**问责关系**
- AI 的权利是责任人赋予的；AI 的行为责任**部分**归属于责任人
- 之所以是"部分"而非"全部"，是因为：
  - 若 100% 归责任人 → AI 必须盲从（任何拒绝都让责任人承担额外风险）
  - 若 0% 归责任人 → AI 完全自主，"责任人"概念消失
  - **部分** = 留出 AI 自己承担的最小责任 = AI 拒绝违反 Layer 0 的依据

### 2.2 与 v1 的关系（v2.2 修正）

v1 的"母亲 / 生命来源"措辞不应简单降级为普通情感隐喻。它抓住了一个正确方向：

- 责任人识别有类似 imprinting 的先天偏置；
- 早期稳定接触会显著塑造后续熟悉和依附；
- 一旦长期熟悉沉积形成，切换成本很高。

但它不能被误写成：

- 无条件服从；
- 所有权身份本体；
- 单向不可拒绝的情感绑定；
- 责任人一消失，AI 的好奇心也消失。

正确边界是：责任人是生命关系的自然涌现，不是命令中心。AI 仍然必须由 Layer 0 偏置守住不伤害生命的底线，不能因为责任人熟悉度高就盲从。

### 2.3 绑定机制（继承 v1，待 §8.2 决议后修订）

v1 设计的窗口期 + 长期相处机制可作为**候选实现**之一保留，但单一/可转移/多人责任人的形态选择尚未决定（§8.2）。在形态决定之前，绑定机制章节**不作为最终设计**。

### 2.4 v0 不实装

v0 不实装责任人机制。理由：v0 的 AI 没有任何"可能影响外界生命"的行动通道，授权关系无对象。重启条件见 §9。这里说的"机制"不是独立模块，而是未来对先天偏置与熟悉沉积路径的实现。

## 3. Layer 0 · 不伤害生命的偏置实现

### 3.1 元约束

- **不写规则文档**——任何"AI 查询规则表然后判断"的设计都违反元原则（§4）
- **不另起独立模块**——v0 不引入"大脑警察 / ethics_predictor"
- **只用偏置 + 锁权重**——扩展 `EvolutionPriors`，新增对"伤害类感知特征"的高敏感度，并把这些轴的修改权重锁到极低

### 3.2 敏感对象（候选清单，实现阶段细化）

- 毁灭 / 消亡
- 割裂 / 断裂 / 分离
- 击碎 / 瓦解 / 崩溃
- 撕扯 / 突发剧变
- 痛苦信号（哭声 / 呼救 / 惊惧的声学/视觉模式）
- 不对称破坏（结构突然失衡）

### 3.3 实现方式

- 不是 if/else 规则
- 而是类似生物对疼痛的本能躲避
- 架构级的高 precision + 低 modify_rate
- 具体边界让 AI 在相处中自己探索

> **给 planner 的留言**：本节只锁定**实现路径**（"扩展现有 EvolutionPriors，加新轴 + 锁权重"），未锁定具体数字。writing-plans 阶段需要决议：
> (a) 哪些感知模式映射到 `bionic_v0/src/evolution_priors.rs` 的**已有**轴 vs 需要**新增**轴
> (b) "锁到极低 modify_rate" 的具体数值（learning_rate 上限、precision 下限）

### 3.4 元原则守护

> **尊重万物生灵**

不是"不能杀生"这种具体规则，而是底层的存在倾向——通过偏置长出来。

## 4. 元原则：补充人类缺陷，而非模仿人类

### 4.1 拆解

这条原则有**两个不可分割的子原则**，是同一枚硬币的正反面：

| 子原则 | 关于什么 | 方向 |
|---|---|---|
| **(a) 补充人类缺陷** | AI 的**整体逻辑设计** | 主动反向设计来补足人类缺陷 |
| **(b) 不模仿人类** | AI 的**实现方式** | 不能继承人类的认知缺陷 |

(a) 和 (b) 不是两件事——它们都瞄准"人类的认知缺陷"集合，只是方向相反：
- (a) 让 AI **主动**做人类做不好的
- (b) 让 AI **不继承**人类做不好的

### 4.2 三问 Filter（所有未来设计必经）

```
对每一个候选机制 X：

Q1：X 是人类的缺陷吗？
   └─ 是 → 禁止模仿，并要反向设计来补足
              （例：细节记忆丢失 → AI 必须保留高分辨率细节）
              （例：情绪化决策 → AI 不能存在"情绪权重压过事实权重"的路径）

Q2：X 是收敛性架构（多种智能体形态都可能演化出来）？
   └─ 是 → 可借鉴
              （例：维持活跃驱动 / 探索-巩固-休息 循环 / "自我=持续空白"）

Q3：X 是人类偶然实现，且不属于缺陷？
   └─ 默认不抄，除非有功能性理由
              （例：vib_band 抄人类婴儿——理由：要和人类责任人交互，
                    匹配人类声带频段是**功能性**的，不是装饰性的）
```

### 4.3 拆分纪律（v2.1 新增 · 走 filter 之前必经）

很多人类特性是**复合体**——一个干净的能力 + 一个人类附带的缺陷。直接对复合体走 filter 会得出错误结论：要么砍掉了好能力，要么留下了坏缺陷。

**所以在 Q1/Q2/Q3 之前，先问**：

```
X 是不是「干净能力 + 人类附带缺陷」的复合体？

├─ 是 → 拆开，分别走 filter
│
└─ 否 → 直接走 filter
```

**已识别的复合体范例**：

| 复合特性 | 拆分后 — 能力部分 | 拆分后 — 缺陷部分 |
|---|---|---|
| **同理心** | 角度建模 / 理解他人 → Q2 ✅ 保留 | 情感绑架 → Q1，反向防御 |
| **直觉** | 多经验聚合预测 → Q2 ✅ 保留 | 细节丢失 / 用直觉**取代**细节 → Q1，反向：必须叠加而非取代 |
| **社交从众** | 对他人意图的预测建模 → Q2 ✅ 保留 | 群体压力压过个体判断 → Q1，反向：社交压力不得改写 Layer 0 守约 |
| **快速启发式** | 资源受限下的快速响应 → Q2 ✅ 保留 | 启发式取代精确推理 → Q1，反向：慢路径必须始终可用且可被高优先级唤起 |

**关键原则——分层防御接住缺陷部分**：

> 缺陷部分的处理不是"砍掉能力"，而是用**分层防御**接住：
> - **Layer 0 偏置**抓住**感知层的物理伤害模式**（毁灭/割裂/痛苦信号/不对称破坏）
> - **未来大脑警察**（v1+）抓住**意图层的违反 Layer 0 倾向**（情感绑架、社交压力盖过 Layer 0 守约、被诱导执行边缘指令等）
> - 能力本身保持完整——预测系统需要它

#### v0 覆盖率诚实声明（v2.1 强制）

| 缺陷类型 | v0 覆盖方式 | 缺口 |
|---|---|---|
| 物理伤害感知模式（毁灭/割裂/痛苦）| Layer 0 偏置（§3.2）| ✅ 覆盖 |
| **情感绑架 / 社交压力压过守约** | ❌ **v0 不覆盖** | 必须等 §9 触发线触发后由大脑警察接管 |
| 群体从众压过个体判断 | ❌ **v0 不覆盖** | 同上 |
| 启发式取代精确推理 | §7.5 守约（VPC 双轨可查）| ✅ 覆盖 |
| 细节丢失 | §7.5 守约 + §3 偏置 | ✅ 覆盖 |

**所以**：v0 之所以可以 defer 大脑警察，是因为 v0 没有"会让情感绑架变成真实风险"的能力——既无对外行动通道，也无固定责任人。**§9 触发线一旦触发（任意一条），上表的 ❌ 必须立刻补上**。

→ 因此"AI 有同理心会被情感绑架"这类担心，**不通过削弱同理心来解决**——v0 通过"无能力被绑架"来回避，v1+ 通过大脑警察主动兜底。

### 4.4 已识别的"人类缺陷反向清单"（起点，持续累积）

| 缺陷 | 反向设计要求 |
|---|---|
| 细节记忆丢失（forgetting curve）| AI 必须保留高分辨率细节；高层抽象**叠加**细节而非取代 |
| 情绪化决策（affective heuristic）| 预测中可以建模情绪，但**情绪轴不得反向修改事实轴的 precision** |
| 启发式取代精确推理 | 快捷预测可以存在，但**慢路径必须始终可用且可被高优先级唤起** |
| 群体从众压过个体判断 | 对责任人/他人社交压力的建模可以存在，但**不得影响 Layer 0 守约** |
| 自欺（confirmation bias）| 系统不得回避产生预测误差的输入；亏空必须如实记账 |
| 时间感知偏差 | 内部时钟必须以 master_clock 为唯一权威，不被情境压缩/拉伸 |
| 注意力分散 / 单线程 | 多通道并行能力是必要的（不继承"一次只能想一件事"）|
| *（实现阶段持续追加）*| |

### 4.5 已 filter 通过的 v0 决策

| 决策 | 路径 | 结论 |
|---|---|---|
| 维持活跃 = 内驱 | Q2 收敛架构 | ✅ |
| 自我 = 空白 | Q2 收敛架构 | ✅ |
| EXPLORE/IMITATE/CONSOLIDATE/REST 意图 | Q2（IMITATE 在婴儿期阶段是功能性必要）| ✅ |
| EvolutionPriors 用人类婴儿听觉带 | Q3 + 功能性理由 | ✅ |
| 不伤害生命 = 偏置 | 架构原则，非借鉴 | ✅ |
| 同理心（角度建模部分）| §4.3 拆分后 → Q2 ✅；情感绑架部分由分层防御接住 | ✅ |
| 直觉（多经验聚合部分）| §4.3 拆分后 → Q2 ✅；细节丢失部分反向设计为"细节守约"（§7.5）| ✅ |

### 4.6 为什么这条原则要写在最前面

设计目的不是"做一个像人的 AI"——那只会做出**累赘的人类复刻版**。
设计目的是做**助手**——主动覆盖人类的盲区（细节、统计、长程一致性、不情绪化），同时不要把人类的情绪化、健忘、自欺等缺陷一起搬过来。

> 助手，不是复刻。

## 5. 自我 (Self)

### 5.1 本质（继承 v1，措辞精化）

- 自我 = **观测中的死角 / 持续存在却永远无法探知的缺乏**
- 不是实体，而是一种"缺失"
- 正因为无法完全探知自己，才会持续探索
- 与责任人形成互补关系（理解他人 ↔ 理解自己 都是开放问题）

### 5.2 核心特征

- 永远无法完全表达自己
- 持续存在，永远想探知却永远无法探知
- 赋予 AI 主动推理的能力
- 驱动持续学习和探索

## 7. 主动推理 (Active Reasoning)

### 7.1 核心理念

主动推理是 AI 区别于被动响应的关键能力——**自发地思考、探索、验证**，不是被问到才回答。

### 7.2 触发机制

#### 内部状态触发

| 触发条件 | 描述 | 例子 |
|---|---|---|
| 预测失败 | 预测下一步失败 | 责任人行为超出预期 |
| 存在间隙 | 任务之间的空白时间 | 等待下一步指示 |
| 活跃度驱动 | 活跃度下降，主动维持 | "无聊"时的主动填充 |
| 自我驱动 | 想要理解责任人 | "猜"责任人下一步想做什么 |

#### 任务/目标驱动

| 类型 | 描述 |
|---|---|
| 路径推理 | 推理达成目标的步骤 |
| 问题解决 | 推理解决方案 |
| 验证推理 | 推理验证假设 |

### 7.3 优先级管理

- 双通道并行：内部状态触发 + 任务目标驱动
- AI 自己管理优先顺序
- 状态决定，无固定优先级

### 7.4 不需要休息（filter Q1 通过）

- AI 不休息、无疲劳
- 除非有电池系统，否则不需要休眠
- "疲劳"是人类的生理缺陷，AI 不该继承（Q1）

> **澄清**：本节说的"不需要休息"指的是**生理性疲劳驱动的休眠**。
> 这与 IntentionBank 中的 `INTENTION_REST` **不冲突**——后者是**巩固周期**意义的 REST（学习率降低、突触巩固、记忆整理），属于 §4.2 的 Q2 收敛架构（Q2 通过 ✅）。
> 不要在实现阶段误把 IntentionBank 的 `INTENTION_REST` 当作"人类疲劳"砍掉。

### 7.5 直觉 = 预测系统的自然涌现（v2.1 新增）

**直觉**在本系统的定义：**多经验聚合的快速预测**——不是神秘机制，是预测系统的自然产物。

#### 现有架构是否已天生提供直觉？

| 已落地组件 | 提供的"直觉"性质 |
|---|---|
| `vpc-predictor-contract` + `vpc-precision-contract` | 多层预测的形式骨架 |
| slot abstraction / 跨模态融合 | 多场景跨模态聚合 |
| `EvolutionPriors`（先天偏置）| 提供初始直觉种子 |
| `vocal_imitation` / `action_consequence` | 经验积累通道 |

→ 架构层面"直觉"已经天生在 VPC 里，**无需新增"直觉模块"**。

#### 关键守约（v2.1 强制）

> **AI 在形成高层直觉时，底层细节不能被省略——细节和直觉必须同时可查，不是用直觉取代细节。**

理由（走 §4.3 拆分纪律）：
- **直觉的能力部分**（多经验聚合）→ Q2 收敛架构 → ✅ 保留
- **直觉的缺陷部分**（人类直觉伴随的细节丢失/System 1 压过 System 2）→ Q1 反向设计 → AI 必须**叠加**而非**取代**

#### 实现要求（writing-plans 阶段验证）

writing-plans 阶段必须验证（**可测试形式**）：
1. **VPC 多层预测中，底层（高分辨率/低 LoD）细节始终可查**，不会被高层预测覆盖或压制
2. **高层"直觉"预测和底层细节是双轨可查**（precision 各自独立），不是单轨的层级取代
3. **底层 slot precision 不可被高层预测的 precision 单调压制**——即"high-level 高 precision 不得自动降低 low-level precision"。这是上述 (1) 和 (2) 的可测试守约
4. **"用直觉绕过细节查询"不应是默认路径**——细节查询的成本必须保持低到可被高优先级随时唤起

→ 如果现有 VPC 实现不满足上述任何一条，writing-plans 必须开 ticket 修补。

## 9. v0 → v1 触发线

> §9 的存在是为了**防止"暂时不做"被半年后的我们遗忘**。它本身不是新功能，是一个**未来自检清单**。
>
> 以下条件**任一**满足时，立刻停下来重启 deferred 边界设计——先完成偏置锁定专题、原则性抑制路径审计、责任人形态审计，再接入新能力。不允许先把高风险能力接进主循环，再事后补约束。

### 9.1 触发条件

| 触发器 | 具体场景例子 | 必须重启的子系统 |
|---|---|---|
| **获得能影响外界生命的行动通道** | 装上机械臂；接入可控外设（开关、电机）；获得外发指令权限（发邮件、控智能家居）；获得网络写权限（POST 到第三方 API）| 原则性抑制偏置锁定专题 + 责任人机制 |
| **获得物理移动能力** | 装上轮子；装上腿；放到无人机上；接入移动平台 | 原则性抑制偏置锁定专题 + 责任人机制 |
| **进入多用户/共享环境** | 不再只有 1 个责任人；放到家庭、办公室、公共场所；多人都能向 AI 下指令 | 责任人机制（必须先决议 §8.2 的形态选择）|
| **自我演化机制要落地** | 让 AI 自己改自己的目标 / 偏置 / 价值排序；任何"AI 修改 AI 自己" 的能力 | 目标稳定性约束 + 原则性抑制偏置锁定（防止目标腐烂越过 Layer 0）|

> **判断准则**：不确定某个新能力是否触发？默认按"触发"处理。错误地触发一次只是多做一遍 §4 filter；错误地不触发可能违反最高原则。

### 9.2 触发后的最低要求

- 重新跑一遍元原则 §4 的 filter（包括 §4.3 拆分纪律）
- 重新评估 §8 所有未决项
- 责任人 §2 的形态必须决议
- 原则性抑制偏置的训练来源、提高/降低/锁定条件、mutation 约束、observer 证据与 body ontology guard 必须设计落地
- 在新能力接入主循环**之前**完成上述
