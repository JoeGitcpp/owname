## 1. 文档定位与硬边界

本 spec 不定义具体行为功能，不定义“主动模块”“探索引擎”“发声器官”，也不直接设计任何具体动作输出实现。

它只定义两类内容：

1. 在什么抽象条件下，一个持续运行的系统会从内生活动自然转入主动探针发起。
2. 一个动作通道要成为早期主动学习的合法载体，最低必须满足什么法则与合同。

本 spec 的硬边界如下：

- 允许预设的只有学习法则、身体法则、更新约束和安全硬边界。
- 不允许预设世界内容边界。
- 不允许由工程师写死对象范围、目标范围、结果边界、重要性地图、探索范围。
- 不允许把“AI 这次在学什么”写成固定程序字段。
- 任何边界若需要存在，都必须解释它如何在探索中形成、如何漂移、如何被修正、如何崩解。
- 不得把好奇心、探索时机、延迟探索、背景浮现先翻译成少量控制数字，再拿这些数字反过来定义理论本体。

因此，本 spec 研究的不是“AI 应该主动做什么”，而是：

**一个持续运行的系统，在不依赖语言、不依赖外部任务、不依赖预写世界分类的前提下，为什么会开始试探；以及什么样的探针通道，才足以支撑这种试探进入学习闭环。**

## 2. 主动性触发法则

### 2.1 静默不是默认终态法则

在持续内生活动系统里，“当前没有外部任务”不等于“应永久静默”。

只要内部仍存在以下任何一种情况，系统就不应被定义为彻底静止：

- 未闭合预测
- 局部高不确定性
- 长期未确认的关系结构
- 历史上可通过探针显著降低不确定性的区域
- 局部稳定性不足但尚未崩塌的路径

静默只能是暂时的低活动状态，而不是系统的自然终点。

### 2.2 探针发起阈值不是数字门，而是结构转折

系统不应随机外放动作，也不应无限压抑动作。

探针之所以会发起，不是因为某个单独阈值数字被触发，而是因为当前架构出现了这样一种结构状态：

- 某个未闭合区域足够显眼
- 它与当前主结构存在足够粗壮的关系纽带
- 局部探索成本不至于打断主结构连续展开
- 当前环境允许低风险试探
- 继续静默不会比试探带来更好的结构收敛

因此，主动性触发不是“冲动”，也不是工程调度，而是当前活跃结构中的自然转折点。

### 2.3 探针抑制法则

主动性不是越多越好。

以下结构条件成立时，探针应自然被压制、推迟或换路：

- 目标空缺虽显眼，但与当前主结构关系过弱
- 局部探索成本会严重打断当前更粗壮的结构闭环
- 当前环境不适合低风险试探
- 历史上同类试探反复无法形成稳定收敛
- 当前前台结构远未闭合，且切换会导致更大失配

因此，主动性不能被理解为“只要好奇就立刻动”，而应被理解为“在结构允许时，试探才会自然发生”。

### 2.4 探针延续、暂停与终止法则

探针发起之后，系统必须持续处于评估中：

- 若试探后的变化持续让当前空缺更清晰，探针会延续。
- 若试探后的变化没有形成更强结构收敛，探针会减弱或暂停。
- 若试探后的变化揭示出真正值得探测的不是原路径，而是邻近结构，探针会换路。
- 若试探已足够澄清当前空缺，探针会自然终止。

因此，探针不是一个瞬时开关，而是一段可持续演化、可中止、可转向的结构过程。

### 2.5 主动性不是目标内容，而是“现在值得试一下”

主动性不意味着系统预先知道最终要学到什么内容。

它只意味着：

- 某个空缺在当前架构里足够显眼
- 这个空缺值得试探
- 当前有合法低成本通道可试
- 当前关系结构允许这样试
- 试探本身比继续完全静默更可能带来结构收敛

因此，主动性触发的本质不是预先知道目标内容，而是判定：

**现在值得合法地试一下。**

## 3. 低成本探针通道的最小抽象合同

一个通道要成为早期主动学习的合法探针，不是“能输出动作”就够了，而必须满足以下合同。

### 3.1 低成本合同

探针通道必须允许高频尝试，而不会因单次试探就带来过高能量代价、过大结构扰动或不可逆后果。

### 3.2 低风险合同

早期探针优先选择失败成本小、误触代价低、不会轻易污染本体稳定性的输出形式。

### 3.3 可连续调节合同

探针通道必须允许强度、时长、节律、频率或形态的连续变化，便于逐步逼近和边界试探。

### 3.4 可重复合同

同类探针必须能在相近条件下反复发起，否则系统无法积累稳定统计与比较历史。

### 3.5 可自感知合同

系统必须能够再次感知自己输出后的结果，至少知道：

- 输出是否真的发生
- 输出后自身或环境是否产生了可观测变化

### 3.6 可时间对齐合同

探针输出及其后果必须能进入统一时间结构，使系统比较：

- 发起时刻
- 延迟
- 持续时间
- 尾波和后续影响

### 3.7 不预写内容边界合同

探针通道即使具备输出能力，也不得要求工程师预先规定：

- 这次探针最终应学哪个对象
- 结果边界在哪里
- 什么一定算主结果
- 什么一定算意外结果

这些内容边界如果存在，必须由探索历史自己学出。

因此，一个合法探针通道不仅要“能输出”，还要允许：

**边界在探索中形成，而不是在探针前被写死。**

## 4. 可学习关注场与边界形成法则

探针事件不是无目标动作，但它的目标也不应被预写成固定切片。

### 4.1 关注场不是目标字段，而是探索诱发的学习偏置

每次探针发起时，系统不会“知道最终边界是什么”，但会围绕当前活跃对象、关系、时间片形成一个初始关注场。

这个关注场不是固定目标切片，而是：

- 当前结构最可能被本次试探影响的区域
- 当前最值得继续追踪的变化带
- 当前最可能显露新耦合的局部结构

### 4.2 边界必须在探索中形成

关注场的边界不是预设的，而是在探索历史中逐步形成：

- 稳定耦合的变化会把边界拉实
- 长期无关的变化会被排出边界
- 邻近但反复相关的变化会让边界扩张
- 原本中心区域若长期无效，边界会收缩或漂移
- 若旧结构无法解释新变化，边界会被重构

### 4.3 学习关注维度不是新本体轴

系统在主动学习中，的确会逐步偏向某些学习维度，例如：

- 可控性
- 耦合强度
- 延迟
- 稳定性
- 可重复性
- 结构闭合收益

但这些不是 tier 0 新轴，不是语言单位，不是概念单位。它们只是学习更新的偏置方向。

### 4.4 结果边界不是分类器，而是当前学习状态的暂时分化

探针后的变化不能被工程师静态分成“目标结果 / 溢出结果 / 意外结果”。

更符合本架构的写法是：

- 当前关注场中心的稳定耦合变化，逐步成为主学习结果
- 位于边缘但反复相关的变化，会修改边界
- 长期超出当前边界却反复被带出的变化，会迫使系统重构关注场

因此，“主结果”“边缘结果”“意外结果”都只是当前学习状态中的暂时结构，不是永久字段。

## 5. 与当前 cleaned substrate 的映射与真实缺口

### 5.1 当前已经承载的前提

当前 cleaned substrate 已经具备以下前提：

- 共享持续运行的基底
- predictor / err / precision 风格更新
- 多时间尺度结构
- snapshot / history / memory summary 提供的历史可回看性

这说明系统已经足以承载主动性法则研究，不再是纯 request/response 工具链。

### 5.2 当前只有雏形、尚未正式化的部分

当前仍然只是影子的部分包括：

- 精度与资源再分配的统一法则
- 局部失败局部修复的统一法则
- 可逆捷径形成与撤销的正式 substrate
- 语言 binding 与更早层主动学习之间的严格接口次序

### 5.3 当前明确缺失的关键法则

1. **低成本探针通道缺失**  
当前 `bionic_v0` 仍然是 perception-first substrate，没有正式动作探针层。

2. **动作输出后的自感知回流缺失**  
即使未来有输出，如果没有回流感知，就不会形成主动学习闭环。

3. **动作-后果时间对齐合同缺失**  
当前系统还没有正式 contract 来回答：某次试探带来了哪些后续变化。

4. **可学习关注场与边界形成法则缺失**  
当前系统还不能真正“自己学会范围”，只能等待工程师解释。

5. **主动性触发法则缺失统一定义**  
当前系统有持续运行背景，但还没有正式回答：什么结构状态足以合法发起一次主动探针。

### 5.4 本章判断

当前 cleaned substrate 已经能解释为什么主动性在原则上可能出现，但还不能让主动探针作为真实外显行为自然发生。

缺的不是“主动功能”，而是：

- 主动探针法则
- 合法探针通道合同
- 动作-后果闭环
- 可学习关注场与边界形成法则

## 6. 与下一份子 spec 的接口边界与禁令

### 6.1 本文档到此为止

本 spec 只负责回答：

- 为什么会开始试
- 什么样的通道才值得作为合法探针
- 探针的关注场与边界为什么必须自己学会

它不继续回答：

- 探针之后的完整动作-后果闭环怎样形成
- 模仿怎样做自他比较
- fast-path 怎样正式形成
- 具体输出器官如何实现

### 6.2 下一份子 spec 的起点

下一份子 spec 应以：

**动作-后果闭环与模仿法则**

为主题，专门回答：

- 输出如何重新进入感知
- 探针与后果如何做时间对齐
- 外部模式如何短时保持
- 自身输出如何与外部模式比较
- 模仿如何作为曲线逼近出现

### 6.3 本文档的硬禁令

- 禁止从现象名直接造模块
- 禁止把主动性翻译成一个人格核
- 禁止把探索时机压成少量控制数字
- 禁止把“忙不忙”写成第一决定因素
- 禁止预写对象范围、目标范围、结果边界
- 禁止把好奇对象的延迟保留写成计数器
- 禁止把浮现写成调度变量
- 禁止让语言层解释主动探针
- 禁止把学习关注维度误写成本体新轴

### 6.4 收束结论

主动性在本架构中不是模块，而是一种由持续内生活动、未闭合偏差驱动、结构连续性、局部探索成本、合法低成本探针通道以及可学习边界形成共同生成的现象。

因此，当前研究的正确目标不是实现具体主动行为，而是先把这些底层法则写清楚，并严格禁止把它们重新压扁成程序字段。
