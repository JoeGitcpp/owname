# Self As Persistent Active Gap Boundary Design

Status: Design boundary for later implementation specs on 2026-05-16.

## Purpose

This document records a correction to the life-design philosophy.

Earlier designs treated personality-like behavior as something that might later
be represented by parameters. That direction is rejected for this project. A
fixed parameter bundle would turn the system back into a program with a styled
surface. It would not preserve the highest principle: silicon-life substrate,
not request/response software.

The admissible replacement is:

`The externally observed self-like continuity is the long-lived pull of
unclosed active gaps formed by prediction, history, probe, return, closure, and
re-entry.`

In plain terms: the system is not given a persona. It accumulates prediction
history. Some structures remain unclosed. Those unclosed structures keep
pulling attention, routing, probe pressure, and re-entry. That durable pull is
the only acceptable early substrate for self-like continuity.

## Boundary

This project must not implement personality as:

- fixed parameter sets;
- named persona profiles;
- identity declarations;
- preference labels;
- prompt style;
- ethical profile objects;
- source ownership fields;
- human imitation targets.

The project may implement numeric substrate for:

- unclosed prediction residue;
- persistent active gaps;
- recurrence of unfinished structures;
- probe pressure caused by unresolved structure;
- closure when action-return evidence reduces the gap;
- re-entry when quiet history replay makes the gap active again.

## Design Law

The system should not be made human-like by copying human categories.

It should grow its own continuity from:

1. passive prediction over external disturbance;
2. active prediction around unclosed structures;
3. pressure produced by what remains unavailable to prediction;
4. legal low-cost probe;
5. return pairing;
6. closure, drift, or re-entry.

The empty region is not a bug. It is the active pull. It is the source of
continued learning.

## High-Risk Term Boundary

`self`, `personality`, and `identity` in this document are external design
terms only. They are not internal ontology units, not engineering ids, and not
body-side state names.

`goal`, `need`, `desire`, and `curiosity` are also external descriptions here.
They must not become fixed body-side modules or fields. The admissible substrate
replacement is numeric active-gap pressure formed from prediction residue,
history recurrence, probe-return closure, and re-entry.

`human` and `imitation` are used only to reject direct copying as a design
principle. The system should not be built by prescribing human traits. It may
use curve comparison and action-consequence learning where already allowed by
existing frozen specs.

This boundary does not violate the language axioms because it does not create
names, labels, tokens, words, semantic units, concept ids, or identity fields.

## Consequence For Active Reasoning

Active reasoning must not be implemented as a timer-driven task runner or a
fixed target planner.

It should be implemented as a substrate process where:

- prediction and relation history form unclosed active gaps;
- active gaps persist across cycles;
- active gaps can drive probe pressure;
- probe-return evidence can reduce or close the gap;
- quiet history can bring a gap back into activity;
- all exposed evidence remains numeric and observer-readable.

This boundary is the philosophical parent for Active Reasoning Persistence v0.
